Editor preference describing how the project presents its server and client targets; it never grants deployment or runtime authority.


```graphql
enum CrowdyStudioPairingPreference {
  PAIRED
  INDEPENDENT
  SERVER_ONLY
  CLIENT_ONLY
}
```


### Values

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioPairingPreference.<b>PAIRED</b></code>](#paired) \{#paired\} 
Present server and client sources as two coordinated halves of one Crowdy Studio project.


#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioPairingPreference.<b>INDEPENDENT</b></code>](#independent) \{#independent\} 
Present server and client sources independently without an implied requirement edge.


#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioPairingPreference.<b>SERVER&#x005F;ONLY</b></code>](#server-only) \{#server-only\} 
Present only the server-target authoring workflow.


#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioPairingPreference.<b>CLIENT&#x005F;ONLY</b></code>](#client-only) \{#client-only\} 
Present only the client-target authoring workflow.
