Lifecycle state of an app. Independent of AppVisibility; the public marketplace lists only LIVE apps. Only ARCHIVED changes who may play; otherwise the app's access tiers decide.


```graphql
enum AppStatus {
  DRAFT
  LIVE
  ARCHIVED
}
```


### Values

#### [<code style={{ fontWeight: 'normal' }}>AppStatus.<b>DRAFT</b></code>](#draft) {/* #draft */} 
Work in progress: never listed in the marketplace. It refuses no player; to keep players out, remove the app's free default access tier and grant access explicitly. Set via updateApp; new apps default to LIVE.


#### [<code style={{ fontWeight: 'normal' }}>AppStatus.<b>LIVE</b></code>](#live) {/* #live */} 
Published; listed in the public marketplace when visibility=PUBLIC.


#### [<code style={{ fontWeight: 'normal' }}>AppStatus.<b>ARCHIVED</b></code>](#archived) {/* #archived */} 
Soft-deleted via archiveApp: retained but read-only and excluded from the marketplace. While archived, players are refused app tokens and refreshes; holders of manage&#x005F;apps or moderate&#x005F;safety on its organization still get one. Reversible by setting status back to DRAFT or LIVE.
