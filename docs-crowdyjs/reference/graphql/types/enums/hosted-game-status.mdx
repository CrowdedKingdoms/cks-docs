Whether a hosted game is served. LIVE: served at its launchUrl. DISABLED: switched off by its developer (setHostedGameEnabled). TAKEN&#x005F;DOWN: removed by an operator; the developer cannot publish or re-enable until an operator restores it.


```graphql
enum HostedGameStatus {
  LIVE
  DISABLED
  TAKEN_DOWN
}
```
