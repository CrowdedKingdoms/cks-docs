Durable lifecycle state of an owner/app agent session.


```graphql
enum CrowdyStudioAgentSessionStatus {
  ACTIVE
  PAUSED
  CLOSED
  REVOKED
}
```


### Values

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentSessionStatus.<b>ACTIVE</b></code>](#active) \{#active\}

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentSessionStatus.<b>PAUSED</b></code>](#paused) \{#paused\}

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentSessionStatus.<b>CLOSED</b></code>](#closed) \{#closed\}

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentSessionStatus.<b>REVOKED</b></code>](#revoked) \{#revoked\}
