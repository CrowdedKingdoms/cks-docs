What went wrong, at the granularity an operator would alert on and a developer would fix. One kind per distinguishable remedy: an expression timeout and a watchdog termination are both "ran too long" and are kept apart because one rolls back a transaction and the other kills a worker thread.


```graphql
enum UserCodeFaultKind {
  EXPRESSION_TIMEOUT
  GAS_EXHAUSTED
  CALL_LIMIT_EXCEEDED
  EXPRESSION_ERROR
  WASM_TRAP
  FUEL_EXHAUSTED
  MEMORY_EXCEEDED
  WATCHDOG_TERMINATED
  MODULE_LOAD_FAILED
  BINDING_MISMATCH
  RESPONSE_TOO_LARGE
  SANDBOX_POISONED
  WORKER_EXIT
  HOST_CALL_FAILED
  UNKNOWN_HOST_FUNCTION
  INTERNAL_ERROR
  DB_OPS_EXCEEDED
  EGRESS_BUDGET_EXCEEDED
  STATE_WRITE_BUDGET_EXCEEDED
  RATE_LIMIT_EXCEEDED
  QUOTA_EXHAUSTED
  CONTRACT_VALIDATION_FAILED
  PLATFORM_BUSY
  CIRCUIT_OPEN
  DISABLED_BY_POLICY
}
```
