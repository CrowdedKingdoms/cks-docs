A rung of the mods kill ladder: one mod (target: its mod id), a player’s mods (their user id), a grid’s mods (its grid id), the installs of a marketplace listing (its listing id), or every mod in the app (no target).


```graphql
enum ExecModScope {
  MOD
  PLAYER
  GRID
  LISTING
  ALL
}
```
