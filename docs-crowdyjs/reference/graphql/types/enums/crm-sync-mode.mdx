Operator only. The Twenty sync's mode: OFF queues nothing; SHADOW queues and builds each record and sends nothing; LIVE writes to the CRM (and acts as SHADOW where this environment has no key).


```graphql
enum CrmSyncMode {
  OFF
  SHADOW
  LIVE
}
```
