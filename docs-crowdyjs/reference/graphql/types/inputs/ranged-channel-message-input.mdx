Input for publishing a channel message that only reaches members near an origin chunk. A member receives it when one of its live actors is in the same app within maxDistance chunks of the origin, measured as the straight-line (Euclidean) distance between chunk coordinates, boundary included; a member with no live actor does not receive it. Members receive an ordinary ChannelMessageNotification. The sender must have the channel send&#x005F;messages permission, exactly as for sendChannelMessage.


```graphql
input RangedChannelMessageInput {
  channelId: BigInt!
  uuid: String!
  payload: String!
  appId: BigInt!
  chunk: ChunkCoordinatesInput!
  maxDistance: Int!
  sequenceNumber: Int
}
```
