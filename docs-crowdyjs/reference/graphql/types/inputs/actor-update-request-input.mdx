Input for sending an actor update request to the UDP game server. This updates the state of an actor (player character or NPC) in a specific chunk.


```graphql
input ActorUpdateRequestInput {
  appId: BigInt!
  chunk: ChunkCoordinatesInput!
  uuid: String!
  state: String!
  distance: Int
  decayRate: Int
  sequenceNumber: Int
}
```
