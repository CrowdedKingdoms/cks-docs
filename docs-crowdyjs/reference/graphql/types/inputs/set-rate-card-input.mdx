#### [<code style={{ fontWeight: 'normal' }}>SetRateCardInput.<b>unitQuantity</b></code>](#unit-quantity)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#unit-quantity\} 
New number of raw metric units one priceCents charge covers, as a BigInt decimal string. Must be &#x003E; 0 and supplied together with unitLabel. Needed because every rate seed is ON CONFLICT DO NOTHING, so a unit corrected in the declaration never reaches a tier that is already installed.


#### [<code style={{ fontWeight: 'normal' }}>SetRateCardInput.<b>acknowledgeRepricing</b></code>](#acknowledge-repricing)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#acknowledge-repricing\} 
Required when a unit change also changes the money. Restating 15c per GiB as 1.396984c per 100 MB is the same price and needs nothing; changing 20c per 100 MB to 20c per GiB-month is a 7841x cut and must be stated deliberately. The mutation refuses rather than guessing which one you meant.
