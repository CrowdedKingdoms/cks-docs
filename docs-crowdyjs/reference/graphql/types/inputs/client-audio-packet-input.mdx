Input for sending a client audio packet (voice chat) to the UDP game server. The audio data is compressed and will be broadcast to nearby players.


```graphql
input ClientAudioPacketInput {
  appId: BigInt!
  chunk: ChunkCoordinatesInput!
  uuid: String!
  audioData: String!
  distance: Int
  decayRate: Int
  sequenceNumber: Int
}
```
