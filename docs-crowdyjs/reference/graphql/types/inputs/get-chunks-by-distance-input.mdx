Arguments for getChunksByDistance: selects chunks within a cubic (Chebyshev-distance) radius around a center chunk, with pagination.


```graphql
input GetChunksByDistanceInput {
  appId: BigInt!
  centerCoordinate: ChunkCoordinatesInput!
  maxDistance: Int!
  limit: Int
  skip: Int
}
```
