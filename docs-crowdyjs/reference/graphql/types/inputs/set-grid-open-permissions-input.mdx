Set the permission keys a grid grants every player with active access to the app (writes the grid&#x005F;open&#x005F;permissions input table): an open build area, a public arena.


```graphql
input SetGridOpenPermissionsInput {
  appId: BigInt!
  gridId: BigInt!
  permissionKeys: [String!]!
}
```
