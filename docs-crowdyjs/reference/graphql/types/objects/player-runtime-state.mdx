The caller's per-app player runtime gate state (the app runtime&#x005F;status twin, player-scoped): 'active', 'grace', or 'denied' with a typed reason. Non-active pauses the player's grid compute only — an unfunded wallet stops your mods, not your game.


```graphql
type PlayerRuntimeState {
  userId: BigInt!
  appId: BigInt!
  status: String!
  reason: String
  updatedAt: DateTime!
}
```
