An autonomous process (automation / NPC): a server-driven entry-point function bound to a trigger (schedule or model activity) plus a safety budget and circuit-breaker state.

  runAsUserId: BigInt

  maxTargets: Int!

  lastRunAt: DateTime
  nextRunAt: DateTime
}
