Notification received when another client sends an audio packet (voice chat). Received via the udpNotifications subscription.


```graphql
type ClientAudioNotification {
  appId: BigInt!

  chunkZ: BigInt!
  distance: Int!
  decayRate: Int!
  uuid: String!
  audioData: String!
  sequenceNumber: Int!
  epochMillis: BigInt!
}
```
