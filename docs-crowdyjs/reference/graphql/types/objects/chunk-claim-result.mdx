Authoritative result of an ordinary player claiming one chunk as a new grid under SELF&#x005F;CLAIM. Grid creation, title assignment, and direct ACL grants are committed atomically.


```graphql
type ChunkClaimResult {
  gridId: BigInt!
  lowChunk: ChunkCoordinates!
  highChunk: ChunkCoordinates!
  policy: GridClaimPolicy!
  ownership: GridOwnership!
  moddable: Boolean!
  effectivePermissionKeys: [String!]!
}
```
