The caller's entitlement to a listing (mode 'free' in P4a). Uninstalling never deletes this row; it is the audit trail P4b attaches payment to.


```graphql
type PlayerCodeAcquisition {
  acquisitionId: String!
  listingId: String!
  appId: BigInt!
  mode: PlayerCodeAcquisitionMode!
  status: String!
  expiresAt: DateTime
  unitBudget: BigInt
  unitsConsumed: BigInt!
  acquiredAt: DateTime!
  acquirerUserId: BigInt
  revokedAt: DateTime
}
```
