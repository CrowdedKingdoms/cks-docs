A ck-exec build (dev-tier preview): queued, building, succeeded or failed, with the compiler’s log and, once it succeeds, one module per crate.


```graphql
type ExecBuild {
  buildId: String!
  status: String!
  log: String
  createdAt: DateTime!
  startedAt: DateTime
  finishedAt: DateTime
  artifacts: [ExecBuildArtifact!]!
}
```
