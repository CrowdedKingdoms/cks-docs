A runtime session: an isolated instance scope (e.g. a match or room) for containers.


```graphql
type GmSession {
  sessionId: String!
  appId: BigInt!
  name: String
  status: String!
  createdByUserId: BigInt
  currentTurnUserId: BigInt
  metadataJson: String!
  admission: String!
  maxParticipants: Int
  participantCount: Int!
  hostUserId: BigInt
  hostTerm: Int!
  revision: String!
  endedAt: DateTime
  endReason: String
  createdAt: DateTime!
  presence: String!
  seededContainerCount: Int
}
```
