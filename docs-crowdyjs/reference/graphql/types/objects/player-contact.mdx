Another player in the caller’s contacts list for the app. Contacts are mutual: an accepted contact is in both players’ lists, and it is what a CONTACTS scope admits.


```graphql
type PlayerContact {
  userId: BigInt!
  state: ContactState!
  createdAt: DateTime!
  acceptedAt: DateTime
}
```
