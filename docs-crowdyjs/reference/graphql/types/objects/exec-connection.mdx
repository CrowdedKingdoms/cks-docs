Where and how a game client connects to ck-exec, the hub-and-spoke execution service (dev-tier preview). Open a WebSocket to `{gatewayUrl}/v1/connect?token={token}` before `expiresAt`.


```graphql
type ExecConnection {
  gatewayUrl: String!
  token: String!
  host: String!
  expiresAt: DateTime!
}
```
