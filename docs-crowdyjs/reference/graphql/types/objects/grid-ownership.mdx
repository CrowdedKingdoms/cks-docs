The current first-class ownership record for a grid. Server player code always resolves its execution identity from this record.


```graphql
type GridOwnership {
  gridOwnershipId: String!
  gridId: BigInt!
  appId: BigInt!
  ownerKind: GridOwnerKind!
  ownerRef: BigInt!
  tenure: GridTenure!
  acquiredVia: String!
  acquiredAt: DateTime!
  expiresAt: DateTime
}
```
