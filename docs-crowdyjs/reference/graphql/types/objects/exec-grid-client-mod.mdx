A CLIENT half a grid serves: of a mod on it that is switched on, not stopped by the kill ladder and admitted, running as the grid’s owner. Carries the caller’s consent and trust in its author.


```graphql
type ExecGridClientMod {
  modId: String!
  name: String!
  gridId: BigInt!
  authorId: BigInt!
  listingId: BigInt
  clientVersion: Int!
  digest: String!
  capabilitySummaryJson: String!
  capabilityHash: String!
  tickIntervalMs: Int!
  callerConsented: Boolean!
  authorCapabilitySummaryJson: String!
  authorCapabilityHash: String!
  callerTrustsAuthor: Boolean!
  updatedAt: DateTime!
}
```
