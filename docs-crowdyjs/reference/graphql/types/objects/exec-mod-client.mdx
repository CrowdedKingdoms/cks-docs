The CLIENT half of a mod (dev-tier preview): browser WASM built from a crowdy-client-sdk crate and attached to the mod, which the mod’s grid serves to visitors who consent to it.


```graphql
type ExecModClient {
  modId: String!
  gridId: BigInt!
  name: String!
  ownerId: BigInt!
  clientVersion: Int!
  digest: String!
  sizeBytes: Int!
  capabilitySummaryJson: String!
  capabilityHash: String!
  tickIntervalMs: Int!
  updatedAt: DateTime!
}
```
