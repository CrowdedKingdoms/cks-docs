One failure of code a user wrote, from any of the three engines. Replaces three disagreeing surfaces: a bare error string on the invoke path, a run table that recorded failures and not successes, and a last&#x005F;error slot the next success cleared.


```graphql
type UserCodeFaultRecord {
  faultId: String!
  appId: BigInt!
  engine: UserCodeFaultEngine!
  kind: UserCodeFaultKind!
  blame: UserCodeFaultBlame!
  retryable: Boolean!
  subject: String!
  entryPoint: String
  flowId: String
  gridId: BigInt
  actingUserId: BigInt
  durationUs: String
  budgetUs: String
  unitsUsed: String
  unitsLimit: String
  stepsCompleted: Int
  detail: String
  instanceId: String
  occurredAt: DateTime!
}
```
