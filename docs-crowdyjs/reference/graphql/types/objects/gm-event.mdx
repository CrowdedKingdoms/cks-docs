An audit-log entry recording one function invocation and its outcome.


```graphql
type GmEvent {
  eventId: String!
  sessionId: String
  functionName: String!
  selfContainerId: String
  callerUserId: BigInt
  callerKind: String!
  automationId: String
  paramsJson: String!
  mutationsAppliedJson: String!
  returnValueJson: String
  success: Boolean!
  errorMessage: String
  executedAt: DateTime!
}
```
