Org-level rollup of replication/GraphQL byte totals and GraphQL op counts across all apps in the organization for the time window. WHICH OF THESE YOU PAY FOR: the &#x002A;SendBytes fields are the billable direction, and &#x002A;RecvBytes are metered but do NOT count toward Aggregate Data Volume, the monthly free-tier and overage measure. All byte figures are wire bytes measured at the network interface, including transport and network headers, and after any compression the service applies -- they will not match a client-side byte counter.


```graphql
type OrgUsageSummary {
  orgId: String!
  replicationSendBytes: String!
  replicationRecvBytes: String!
  graphqlSendBytes: String!
  graphqlRecvBytes: String!
  totalOps: String!
}
```
