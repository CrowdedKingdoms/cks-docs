Machine-readable auth scope required to call this field. Enforcement is via server-side guards, not directive execution; super admins bypass org/app permission checks. The field description carries the same requirement in prose.


```graphql
directive @requiresPermission(
  scope: String!
  permission: String!
  scopeArg: String
) on FIELD_DEFINITION
```
