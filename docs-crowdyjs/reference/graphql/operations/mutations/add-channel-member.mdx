Add a user to a channel, or approve their pending join request (upsert to active). Requires the 'manage&#x005F;members' channel permission (app admins bypass). Auto-assigns the default role if configured and notifies Buddy with the member's effective send permission.


```graphql
addChannelMember(
  groupId: BigInt!
  userId: BigInt!
): GroupMember!
```
