Build the CLIENT half of a mod from one crowdy-client-sdk crate (dev-tier preview): compiled for wasm32-unknown-unknown in the build sandbox, fuel-metered and optimized there, checked against the client ABI and at most 512 KiB, with its capability summary derived from the module. Returns at once with the build queued (`kind` `client`); poll `execModBuildStatus`, then attach it with `execModClientDeploy`. One build, server or CLIENT, at a time per player. Requires the 'write&#x005F;client&#x005F;code' permission in the app.


```graphql
execModClientBuild(
  appId: BigInt!
  crate: ExecBuildCrateInput!
): ExecBuild!
```
