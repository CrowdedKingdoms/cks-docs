Delete a container type. Also deletes its property definitions. Refuses if live containers of that type exist, or if functions are bound to it — delete those first. Requires app-admin ('manage&#x005F;apps'). DESTRUCTIVE. Returns true if a type was deleted.


```graphql
gameModelDeleteContainerType(
  appId: BigInt!
  typeName: String!
): Boolean!
```
