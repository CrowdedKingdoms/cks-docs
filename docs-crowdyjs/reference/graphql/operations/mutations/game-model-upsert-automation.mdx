Create or update an autonomous process ("automation" / NPC): a server-driven entry-point function bound to a trigger (schedule | event | manual), an optional run-as identity, a target/candidate selector, and a per-automation safety budget. The entry-point function must be marked autonomousInvocable. Idempotent on (app, name). Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelUpsertAutomation(
  input: UpsertAutomationInput!
): GmAutomation!
```
