Accept another player’s contact request: both become each other’s contacts, and both players’ live sessions learn it within a second. NOT&#x005F;FOUND when that player has not asked. Game plane: send the app-scoped token for this app to the app’s datacenter.


```graphql
acceptContact(
  appId: BigInt!
  userId: BigInt!
): PlayerContact!
```
