Record (or revoke) the caller's consent for their project source in this app to be sent to a model provider through the platform's metered endpoint under ZDR / no-collection routing. Idempotent. Requires 'use&#x005F;studio&#x005F;agent'. SIDE EFFECT: enables (or disables) POST /v1/model/chat/completions for this player and app.
