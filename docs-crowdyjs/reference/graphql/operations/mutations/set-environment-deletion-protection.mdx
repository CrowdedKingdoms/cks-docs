Operator only (is&#x005F;operator). Toggles deletion protection on an environment (when enabled, purgeEnvironment is blocked) and writes an audit entry. Returns true on success.


```graphql
setEnvironmentDeletionProtection(
  environmentId: String!
  enabled: Boolean!
): Boolean!
```

#### [<code style={{ fontWeight: 'normal' }}>setEnvironmentDeletionProtection.<b>enabled</b></code>](#enabled)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean!</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#enabled\}
