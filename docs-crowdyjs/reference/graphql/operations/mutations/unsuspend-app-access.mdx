Lift a user's suspension (suspendAppAccess) before it lapses. A no-op for a user who is not suspended. Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app; super admins bypass.


```graphql
unsuspendAppAccess(
  appId: BigInt!
  userId: BigInt!
): AppUserAccess!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AppUserAccess</b></code>](/reference/graphql/types/objects/app-user-access.mdx) <Badge class="badge badge--secondary " text="object"/>
