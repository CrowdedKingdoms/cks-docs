Enable or disable an automation. Re-enabling also resets its circuit breaker (closed, zero failures, no pause) so a tripped automation resumes. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelSetAutomationEnabled(
  appId: BigInt!
  name: String!
  enabled: Boolean!
): GmAutomation!
```

#### [<code style={{ fontWeight: 'normal' }}>gameModelSetAutomationEnabled.<b>enabled</b></code>](#enabled)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean!</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#enabled\}
