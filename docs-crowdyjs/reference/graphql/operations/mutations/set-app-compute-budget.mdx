Set an app's compute allowance in units per minute, spanning the model expression engine and both WASM tiers. One unit is one millisecond of measured execution time. An over-ceiling value is REFUSED naming the ceiling (6000000 units per minute) rather than accepted and clamped, so the value reported back is always the value in force. Set enforce to true to refuse invokes when the allowance is exceeded; leave it false to record the decision and admit, which is what produces the measurements a threshold should be chosen from. Requires app-admin ('manage&#x005F;apps').


```graphql
setAppComputeBudget(
  appId: BigInt!
  unitsPerMinute: Int!
  enforce: Boolean = false
  note: String
): AppComputeBudgetInfo!
```
