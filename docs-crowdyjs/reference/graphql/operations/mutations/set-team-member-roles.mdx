Replace a member's roles with the given set (not additive — roles not listed are removed). Requires the 'manage&#x005F;roles' team permission (app admins bypass).


```graphql
setTeamMemberRoles(
  input: SetMemberRolesInput!
): GroupMember!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>setTeamMemberRoles.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>SetMemberRolesInput!</b></code>](/reference/graphql/types/inputs/set-member-roles-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\}
The team, the target user, and the full list of role ids the member should have.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GroupMember</b></code>](/reference/graphql/types/objects/group-member.mdx) <Badge class="badge badge--secondary " text="object"/>
A user's membership in a group, including the roles assigned to them.
