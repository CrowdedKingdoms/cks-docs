Arm a one-shot timer: invoke a function once, after a delay. The timer is durable (it survives an API restart) and claimed by exactly one replica, so it fires once. The target function must be autonomousInvocable, because the fire is headless and runs with system authority rather than a player's — which is also why this needs app-admin ('manage&#x005F;apps'). For player-driven delays, author a timers effect on a function instead so the delay is part of your game logic. Supply dedupeKey to make re-arming replace the pending timer rather than queue another fire.


```graphql
gameModelScheduleInvoke(
  input: ScheduleInvokeInput!
): GmTimer!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GmTimer</b></code>](/reference/graphql/types/objects/gm-timer.mdx) <Badge class="badge badge--secondary " text="object"/>
