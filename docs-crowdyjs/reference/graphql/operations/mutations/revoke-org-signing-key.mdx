Revoke a signing key: assertions it signed are refused from now on (sessions already signed in run until they lapse; end them with endManagedPlayerSessions). False when there was no such active key. Requires manage&#x005F;players on the org.


```graphql
revokeOrgSigningKey(
  orgId: BigInt!
  keyId: BigInt!
): Boolean!
```
