Revoke an active player-code admission. Requires 'manage&#x005F;compute'. SIDE EFFECTS: audit row + replica sync; game-api drains affected server modules and blocks client artifact fetches on the next admission refresh.


```graphql
revokeAppCodeAdmission(
  appId: BigInt!
  admissionId: String!
): AppCodeAdmission!
```
