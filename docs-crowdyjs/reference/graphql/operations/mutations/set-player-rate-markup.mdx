Set the app's player rate-card markup (0..10000 basis points on the platform base price). Markup income accrues per charge to the org's income line and is paid out via the P4b payout ledger. Requires 'manage&#x005F;billing'.


```graphql
setPlayerRateMarkup(
  appId: BigInt!
  markupBps: Int!
): Int!
```
