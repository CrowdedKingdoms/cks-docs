Make an earlier ck-exec version active again, a rollback (dev-tier preview). Running instances pick it up when they next start, as after a deploy. Requires the org 'manage&#x005F;compute' permission.


```graphql
execActivateVersion(
  appId: BigInt!
  version: Int!
): ExecAppStatus!
```
