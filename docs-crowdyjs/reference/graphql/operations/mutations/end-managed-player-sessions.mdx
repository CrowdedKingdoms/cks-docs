Dev only. Sign a managed player out everywhere: its sessions and app tokens end, and so do its realtime and ck-exec connections. It can sign in again (use updateManagedPlayer to stop that). False when it held no session. An org token with players:manage, or an org admin with manage&#x005F;players.


```graphql
endManagedPlayerSessions(
  orgId: BigInt!
  externalId: String!
): Boolean!
```
