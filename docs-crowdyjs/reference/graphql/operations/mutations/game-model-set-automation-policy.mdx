Set the app's automation policy (platform guardrails): the kill switch, max automations, the minimum schedule interval floor, max fan-out, max event cascade depth, and the aggregate per-minute run ceiling. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelSetAutomationPolicy(
  input: SetAutomationPolicyInput!
): GmAutomationPolicy!
```
