ADMIN: lifts an account block now. Nothing is restored; the account signs in again. The last block stays readable through accountBlock. Requires a super-admin bearer game token.


```graphql
unblockAccount(
  userId: BigInt!
): AccountBlock!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>unblockAccount.<b>userId</b></code>](#user-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> {/* #user-id */} 
Target user id (BigInt as a decimal string).




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AccountBlock</b></code>](/reference/graphql/types/objects/account-block.mdx) <Badge class="badge badge--secondary " text="object"/> 
A platform-wide block on an account, set by a super-admin. While it holds, every sign-in and every authenticated request is refused with ACCOUNT&#x005F;BLOCKED, on CK and on Crowd Altar, and every session, realtime connection and ck-exec socket the account had was ended when it was set. The last block stays readable after it is lifted or lapses.
