Update a team role's name, rank, and/or permission keys (system roles cannot be renamed/re-ranked). When permissions are supplied they REPLACE the role's existing keys. Requires the 'manage&#x005F;roles' team permission (app admins bypass).


```graphql
updateTeamRole(
  input: UpdateGroupRoleInput!
): GroupRole!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>updateTeamRole.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>UpdateGroupRoleInput!</b></code>](/reference/graphql/types/inputs/update-group-role-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\}
The role id plus the fields to change (omitted fields are left as-is).




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GroupRole</b></code>](/reference/graphql/types/objects/group-role.mdx) <Badge class="badge badge--secondary " text="object"/>
A role within a group (team/channel). Carries the group-management permission keys it grants (e.g. manage&#x005F;members), NOT world/runtime grid permissions.
