Set the app's compute policy (platform guardrails): the kill switch, module count / tick-rate / fuel / memory / runtime / host-op / egress ceilings, and circuit-breaker tuning. Omitted fields keep current values. Requires the org 'manage&#x005F;compute' permission.


```graphql
computeSetPolicy(
  input: SetComputePolicyInput!
): WasmModulePolicy!
```
