Create a directed relationship edge between two containers (the game model is a graph), with a relationship type and optional weight. Requires a valid token.


```graphql
gameModelAddEdge(
  input: AddEdgeInput!
): GmEdge!
```

#### [<code style={{ fontWeight: 'normal' }}>gameModelAddEdge.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>AddEdgeInput!</b></code>](/reference/graphql/types/inputs/add-edge-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\}
The app, the from/to container ids, the relationship type, and an optional weight and metadata.

#### [<code style={{ fontWeight: 'normal' }}><b>GmEdge</b></code>](/reference/graphql/types/objects/gm-edge.mdx) <Badge class="badge badge--secondary " text="object"/>
