Permanently deactivates an org token so it can no longer authenticate. Requires the 'manage&#x005F;tokens' permission on the token's org (super admins bypass). DESTRUCTIVE and irreversible; the secret cannot be reactivated. Returns false if the token does not exist.


```graphql
revokeOrgToken(
  orgTokenId: BigInt!
  idempotencyKey: String
): Boolean!
```

Optional idempotency key. Recommended for retries: replaying with the same key and identical arguments returns the first result instead of re-applying; the same key with different arguments returns IDEMPOTENCY&#x005F;CONFLICT. Keys expire after 24h.
