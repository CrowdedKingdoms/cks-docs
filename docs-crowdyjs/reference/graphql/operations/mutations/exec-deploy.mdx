Deploy a new version of an app's ck-exec topology (dev-tier preview): the manifest and any modules it names that were not uploaded before. The execution manager checks the manifest's tree and bounds and each module's digest, stores them, and makes the version active; running instances pick it up when they next start. Requires the org 'manage&#x005F;compute' permission.


```graphql
execDeploy(
  input: ExecDeployInput!
): ExecDeployResult!
```
