Create a team. Whether the caller may create one is governed by the per-app team policy (app&#x005F;group&#x005F;policies: admin | member | anyone). The caller becomes the owner and is granted a system 'leader' role holding every team permission. New teams default to the app's default membership policy unless overridden.


```graphql
createTeam(
  input: CreateTeamInput!
): Group!
```

#### [<code style={{ fontWeight: 'normal' }}>createTeam.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>CreateTeamInput!</b></code>](/reference/graphql/types/inputs/create-team-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\} 
The app, the team name, and optional description / membership policy override.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>Group</b></code>](/reference/graphql/types/objects/group.mdx) <Badge class="badge badge--secondary " text="object"/>
