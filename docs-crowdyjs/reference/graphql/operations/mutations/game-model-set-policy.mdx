Set the app's game-model runtime policy: who may create sessions (admin | member | anyone) and the default participant role. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelSetPolicy(
  input: SetGameModelPolicyInput!
): GmAppPolicy!
```
