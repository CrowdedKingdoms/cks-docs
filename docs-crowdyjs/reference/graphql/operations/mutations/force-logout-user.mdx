ADMIN/DESTRUCTIVE: revokes ALL of the target user’s sessions by deleting every game&#x005F;token row, forcing re-authentication on every device. Returns true if at least one session was revoked. Requires a super-admin bearer game token (and the management API enabled). NOTE: management-owned in cks-game-api (throws ForbiddenException) — use cks-management-api.


```graphql
forceLogoutUser(
  userId: BigInt!
): Boolean!
```
