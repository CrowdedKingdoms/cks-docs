Links an unlinked app to an existing environment for split-mode routing. Refuses shared apps and apps already linked elsewhere. Requires the 'manage&#x005F;environments' org permission.


```graphql
linkAppToEnvironment(
  input: LinkAppToEnvironmentInput!
): App!
```
