Delete a self-authored player module and its source versions. Only the code author may delete it, and they must still own the target grid. Returns false when no matching module exists.


```graphql
playerComputeDelete(
  appId: BigInt!
  gridId: BigInt!
  name: String!
): Boolean!
```
