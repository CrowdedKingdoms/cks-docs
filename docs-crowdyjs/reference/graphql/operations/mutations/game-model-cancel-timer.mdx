Cancel pending timers by id or by dedupe key, returning how many were removed. A timer already claimed for execution cannot be cancelled. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelCancelTimer(
  appId: BigInt!
  timerId: String
  dedupeKey: String
): Int!
```
