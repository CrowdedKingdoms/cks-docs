Install an acquired listing after consenting to its capability summary (echo the version's capabilityHash as consentCapabilityHash — a mismatch fails closed). Server halves register through the same P1 registry as instances in a grid the caller OWNS (requires run&#x005F;server&#x005F;code) and run as the grid owner on their quota/wallet — never as the author. Bundled client halves attach to the grid for per-visitor consent (D2); omitting gridId makes a personal client-only install. Fail-closed on entitlement, admission, consent, ownership, and run keys.


```graphql
installPlayerCode(
  appId: BigInt!
  acquisitionId: String!
  consentCapabilityHash: String!
  gridId: BigInt
  versionId: String
): PlayerCodeInstall!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerCodeInstall</b></code>](/reference/graphql/types/objects/player-code-install.mdx) <Badge class="badge badge--secondary " text="object"/>
