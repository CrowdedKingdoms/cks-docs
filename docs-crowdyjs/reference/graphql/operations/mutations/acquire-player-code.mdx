Acquire a free listing: writes the entitlement row (no payment edge exists in P4a — paid modes are P4b). Idempotent per (listing, caller). Allowed in any admission mode; in allow&#x005F;list apps an unadmitted acquisition holds until the listing/author/org is admitted, at which point installPlayerCode proceeds.


```graphql
acquirePlayerCode(
  appId: BigInt!
  listingId: String!
): PlayerCodeAcquisition!
```
