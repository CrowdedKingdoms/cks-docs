Define an app feature key that access tiers can be granted. ck-exec code reads the keys a player's tier grants with `ctx.players().features(player)` (scope `players.read`) and gates on them itself. The `gameModel` prefix is a legacy name. Idempotent on (app, featureKey). Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelDefineFeature(
  input: DefineAppFeatureInput!
): GmAppFeature!
```
