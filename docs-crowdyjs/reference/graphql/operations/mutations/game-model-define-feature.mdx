Define an app feature key that functions can gate on (via a tier&#x005F;feature authority rule) and that access tiers can be granted. Idempotent on (app, featureKey). Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelDefineFeature(
  input: DefineAppFeatureInput!
): GmAppFeature!
```
