Bind a trigger to a compute module: a tick loop (tickHz, clamped by policy), an event subscription (model or compute events), or a client-invokable export (with an optional invoke policy). Requires the org 'manage&#x005F;compute' permission.

  input: UpsertComputeTriggerInput!
