Set who may create teams in an app and the default membership policy for new teams. Requires app-admin ('manage&#x005F;apps'). Affects future team creation only, not existing teams.


```graphql
setTeamPolicy(
  input: SetTeamPolicyInput!
): AppGroupPolicy!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>setTeamPolicy.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>SetTeamPolicyInput!</b></code>](/reference/graphql/types/inputs/set-team-policy-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\} 
The app plus the new creation policy, default membership policy, and optional member/group caps.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AppGroupPolicy</b></code>](/reference/graphql/types/objects/app-group-policy.mdx) <Badge class="badge badge--secondary " text="object"/> 
Per-app, per-type policy controlling who may create groups of a type and the default membership policy of new groups.
