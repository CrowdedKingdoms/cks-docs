Restart a module that was stopped for exceeding a resource limit, without deploying a new version. Deploying a fix clears the stop on its own and is the normal path; use this when the limit itself was wrong or the load is being accepted deliberately. The reason is recorded. Requires the org 'manage&#x005F;compute' permission.


```graphql
computeResetBreaker(
  appId: BigInt!
  name: String!
  reason: String!
): WasmModule!
```
