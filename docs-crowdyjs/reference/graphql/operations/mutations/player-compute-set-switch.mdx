Throw or release a player-compute kill switch at player, grid, or app scope (the 03 §7 kill ladder). Throwing a switch stops the covered modules on the next scheduler pass; quota state is retained, and releasing resumes normally. Module-level disable is playerComputeSetEnabled; listing scope arrives with the marketplace. Requires the org 'manage&#x005F;compute' permission.


```graphql
playerComputeSetSwitch(
  appId: BigInt!
  scope: String!
  disabled: Boolean!
  scopeRef: BigInt
  reason: String
): Boolean!
```
