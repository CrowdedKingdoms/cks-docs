Throw or release a player-compute kill switch at player, grid, app, or listing scope (the 03 §7 kill ladder). Throwing a switch stops the covered modules on the next scheduler pass; quota state is retained, and releasing resumes normally. LISTING scope (P4a) disables every install of a marketplace listing fleet-wide — pass the listing UUID in listingRef; pair it with the management-side catalog kill to also stop new acquisitions. Module-level disable is playerComputeSetEnabled. Requires the org 'manage&#x005F;compute' permission.


```graphql
playerComputeSetSwitch(
  appId: BigInt!
  scope: String!
  disabled: Boolean!
  scopeRef: BigInt
  reason: String
  listingRef: String
): Boolean!
```
