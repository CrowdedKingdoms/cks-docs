List automation runs (the monitoring + audit trail of autonomous-process executions) for an app, newest first, optionally filtered by automation name and/or outcome. Each run carries timing, fan-out + invocation counts, billed compute, and any circuit action. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelAutomationRuns(
  appId: BigInt!
  automationName: String
  success: Boolean
  limit: Int
  offset: Int
): [GmAutomationRun!]!
```
