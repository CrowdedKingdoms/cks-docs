Query the function-invocation event log (audit trail) with optional filters and pagination. Useful for debugging functions or showing recent activity. Requires a valid token.


```graphql
gameModelEvents(
  appId: BigInt!
  sessionId: String
  selfContainerId: String
  functionName: String
  success: Boolean
  limit: Int
  offset: Int
): [GmEvent!]!
```
