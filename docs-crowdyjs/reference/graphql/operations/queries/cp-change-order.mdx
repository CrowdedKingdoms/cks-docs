Operator only (is&#x005F;operator). One change order with ordered task and step progress. Durable change orders may return read-only projected rows when exact live execution details are unavailable; planned work remains pending until an outcome is observed or inferred. Null when the id is not found.


```graphql
cpChangeOrder(
  id: String!
): CpChangeOrderDetail
```
