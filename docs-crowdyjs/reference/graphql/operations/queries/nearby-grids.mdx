List every grid overlapping a chunk-coordinate bounding box: its gridId, its bounds and the caller's own permission keys on it. Player-safe: another user's keys need nearbyGridPermissions (app admin). The grid that decides a voxel edit in a chunk is the smallest box covering it (the lower gridId on a tie), and the edit needs update&#x005F;voxel&#x005F;data there. Requires an app-scoped token for the same app.


```graphql
nearbyGrids(
  input: NearbyGridsInput!
): [NearbyGrid!]!
```
