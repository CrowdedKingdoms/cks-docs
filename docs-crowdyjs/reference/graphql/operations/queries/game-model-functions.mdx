List studio-defined functions for an app, optionally filtered to those attached to a container type. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelFunctions(
  appId: BigInt!
  containerTypeName: String
): [GmFunction!]!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>gameModelFunctions.<b>appId</b></code>](#app-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#app-id\} 
The app (tenant) whose functions to list.


#### [<code style={{ fontWeight: 'normal' }}>gameModelFunctions.<b>containerTypeName</b></code>](#container-type-name)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#container-type-name\} 
Optional: only functions bound to this container type. Omit for all functions.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GmFunction</b></code>](/reference/graphql/types/objects/gm-function.mdx) <Badge class="badge badge--secondary " text="object"/> 
A studio-defined function: a named, sandboxed behavior over containers (parameters, declared mutations, optional return, and an authority invoke policy).
