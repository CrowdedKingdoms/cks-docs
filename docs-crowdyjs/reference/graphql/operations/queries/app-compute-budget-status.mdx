Whether an app is inside its per-minute compute allowance right now, which engines its units came from, and whether exceeding the allowance is currently refusing invokes or only being recorded. Shipped in shadow mode: unless an operator has set an enforcing allowance for this app, overBudget can be true while enforced is false. Requires app-admin ('manage&#x005F;apps').


```graphql
appComputeBudgetStatus(
  appId: BigInt!
): AppComputeBudgetStatus!
```
