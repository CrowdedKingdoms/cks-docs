OPERATOR ONLY. The Crowdy Studio agent price list: every model card with its four per-million token prices and its lifecycle status. Separate from billingRateCard because agent pricing is per model rather than per metered dimension. Read-only.


```graphql
agentRateCards: [AgentRateCardEntryType!]!
```


### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AgentRateCardEntryType</b></code>](/reference/graphql/types/objects/agent-rate-card-entry-type.mdx) <Badge class="badge badge--secondary " text="object"/> 
One Crowdy Studio agent model price, in micro-USD per million tokens. Only an ACTIVE row with a model&#x005F;id ever prices a run.
