Read the app's sanitized platform-funded Agentic Studio usage over a bounded time window. Requires 'view&#x005F;compute&#x005F;diagnostics'. Returns exact OpenRouter prompt/completion/reasoning/cache/native token and decimal-USD cost dimensions, request/tool/compile/wall counts, and pinned policy revisions. It never returns prompts, source, private reasoning, headers, provider bodies, credentials, payer references, or wallet data; pilot usage never debits a player wallet.


```graphql
crowdyStudioAgentUsage(
  appId: BigInt!
  since: DateTime
  until: DateTime
  limit: Int
): CrowdyStudioAgentUsagePage!
```
