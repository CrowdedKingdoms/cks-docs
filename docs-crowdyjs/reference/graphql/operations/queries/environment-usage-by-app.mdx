Aggregate replication/GraphQL byte totals per app for the apps linked to an environment, over the time window. Read-only reporting. Requires the 'view&#x005F;usage' org permission.


```graphql
environmentUsageByApp(
  orgId: BigInt!
  environmentSlug: String!
  since: DateTime!
): [AppUsageRollupRow!]!
```
