A snapshot of an app's game-model footprint and recent activity: container/property/edge/session/function/automation row counts, total + 24h event volume, failed + automation-driven invocations, and the most-invoked functions. Helps developers understand what is in their game and their database. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelAppDiagnostics(
  appId: BigInt!
): GmAppDiagnostics!
```
