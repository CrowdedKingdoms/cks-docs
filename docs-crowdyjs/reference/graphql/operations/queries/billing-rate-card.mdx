OPERATOR ONLY. The metered rate card for a scope: every priced dimension with its unit, price, free allowance and the period that allowance resets on. SHARED is organization usage charged to the org wallet as "shared&#x005F;usage"; PLAYER is a player's own metered usage charged to the player wallet as "usage&#x005F;debit". A dimension priced at 0 is metered but not charged. Read-only. Customers read the same rates through `meteredRateCard`, which is public and omits the operator note.


```graphql
billingRateCard(
  scope: RateScope!
): [RateCardEntryType!]!
```
