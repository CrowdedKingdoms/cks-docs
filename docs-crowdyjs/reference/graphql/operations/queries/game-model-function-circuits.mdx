State of the per-function circuit breaker on the player-invoke path (gameModelInvoke) for one app, plus the mode and thresholds the answering instance is running. In the default 'shadow' mode nothing is refused and shadowRefusals counts what enforcement would have refused, so an open circuit means the function has been failing rather than that players are being blocked. A function that has never failed has no row and is absent. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
gameModelFunctionCircuits(
  appId: BigInt!
  name: String
  limit: Int
): GmFunctionBreakerStatus!
```
