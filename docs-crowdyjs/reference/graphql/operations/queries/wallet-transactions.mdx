Lists the organization's wallet transactions (credits and debits), ordered newest first. Use it to audit how the balance changed over time. Requires the 'view&#x005F;billing' org permission.


```graphql
walletTransactions(
  orgId: BigInt!
  limit: Int
  offset: Int
): [WalletTransaction!]!
```
