Bulk twin of gameModelContainerState: identity plus visible property state for up to 500 containers in one call (BAD&#x005F;REQUEST above). The same visibility rules apply per row (public always; owner/hidden depend on the CALLER's relationship to each container). Ids the app does not hold are omitted rather than errors; duplicates are returned once; order follows the input. Use it after paging gameModelContainers to pull a level's state in a few calls instead of one per object. Requires a valid token.


```graphql
gameModelContainerStates(
  appId: BigInt!
  containerIds: [String!]!
): [GmContainerState!]!
```
