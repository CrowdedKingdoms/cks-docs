Guest log lines from an app's ck-exec instances (`ctx.log`), newest first, kept for 24 hours (dev-tier preview). Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
execLogs(
  appId: BigInt!
  nodeType: String
  key: String
  maxLevel: Int
  before: String
  limit: Int
): [ExecLogLine!]!
```
