List the group/role -&#x003E; permission-key grants configured on a grid for one group (rows of the `grid_group_grants` input table). These are inputs to the effective ACL, not the materialized result — use `gridUserPermissions` for a specific user's effective keys. Requires app-admin ('manage&#x005F;apps').


```graphql
gridGroupGrants(
  appId: BigInt!
  gridId: BigInt!
  groupId: BigInt!
): [GridGroupGrant!]!
```
