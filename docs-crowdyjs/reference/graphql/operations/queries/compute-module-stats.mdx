Aggregate compute activity for an app over a recent window: run/failure counts, fuel, egress, and a per-module breakdown. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
computeModuleStats(
  appId: BigInt!
  windowMinutes: Int = 60
): WasmComputeStats!
```
