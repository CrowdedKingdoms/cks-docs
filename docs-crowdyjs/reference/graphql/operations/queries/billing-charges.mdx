The lossless ledger's charge rows for one app: every (payer, meter, period) or request that has been priced, with what was billed, held and written off, in micro-USD. Requires 'view&#x005F;billing' on the org.


```graphql
billingCharges(
  orgId: BigInt!
  appId: BigInt!
  limit: Int
): [BillingCharge!]!
```

#### [<code style={{ fontWeight: 'normal' }}><b>BillingCharge</b></code>](/reference/graphql/types/objects/billing-charge.mdx) <Badge class="badge badge--secondary " text="object"/>
