The calling user's active app authorizations ("connected apps"). Requires a SESSION token.


```graphql
myAuthorizedApps: [AppAuthorizationGrant!]!
```


### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AppAuthorizationGrant</b></code>](/reference/graphql/types/objects/app-authorization-grant.mdx) <Badge class="badge badge--secondary " text="object"/>
A user's standing consent for an app to receive app-scoped tokens via the Overworld portal (the “connected apps” list).
