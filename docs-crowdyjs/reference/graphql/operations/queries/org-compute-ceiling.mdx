What each of the organization's apps may run of compute modules in one datacenter once it is funded: instances placed at once and the memory they reserve, and whether an operator set them for this organization. Requires view&#x005F;compute&#x005F;diagnostics on the org (super-admins and operators bypass). Read-only.
