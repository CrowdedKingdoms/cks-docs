Traverse the container graph from a root container along a relationship type up to a depth, returning the reachable nodes and edges. Requires a valid token.


```graphql
gameModelTraverse(
  appId: BigInt!
  rootId: String!
  relationshipType: String!
  depth: Int = 1
): GmTraverseResult!
```
