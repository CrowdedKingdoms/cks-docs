List an app's player-code admission entries, newest first. Requires 'view&#x005F;compute&#x005F;diagnostics'. By default returns active entries only; includeRevoked adds audit-visible revoked rows. Admission controls execution, never source visibility.


```graphql
appCodeAdmissions(
  appId: BigInt!
  includeRevoked: Boolean = false
): [AppCodeAdmission!]!
```
