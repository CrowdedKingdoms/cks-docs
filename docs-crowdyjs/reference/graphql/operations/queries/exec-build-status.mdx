A ck-exec build's status, compiler log and modules (dev-tier preview); null when this app has no such build. Builds are kept for 7 days. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
execBuildStatus(
  appId: BigInt!
  buildId: String!
): ExecBuild
```
