List sessions in an app, newest first, optionally filtered by status, admission and/or host. Requires a valid token.


```graphql
gameModelSessions(
  appId: BigInt!
  status: String
  admission: String
  hostUserId: BigInt
  limit: Int
): [GmSession!]!
```
