An app's stored compute allowance, or null when none has been set — in which case the app is measured against the platform reference allowance and is never refused. Requires app-admin ('manage&#x005F;apps').


```graphql
appComputeBudget(
  appId: BigInt!
): AppComputeBudgetInfo
```

#### [<code style={{ fontWeight: 'normal' }}>appComputeBudget.<b>appId</b></code>](#app-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#app-id\} 
The app (tenant) whose allowance to read.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AppComputeBudgetInfo</b></code>](/reference/graphql/types/objects/app-compute-budget-info.mdx) <Badge class="badge badge--secondary " text="object"/> 
An app's compute allowance in units per minute, spanning the expression engine and both WASM tiers. Absent when no allowance has been set for the app, in which case the app is measured against the platform reference allowance and is never refused.
