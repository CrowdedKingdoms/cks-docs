A grid's mods (dev-tier preview), which players in the grid call by name as the node type `mod:<name>` with the grid id as key. Requires access to the app.


```graphql
execMods(
  appId: BigInt!
  gridId: BigInt!
): [ExecMod!]!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>ExecMod</b></code>](/reference/graphql/types/objects/exec-mod.mdx) <Badge class="badge badge--secondary " text="object"/>
