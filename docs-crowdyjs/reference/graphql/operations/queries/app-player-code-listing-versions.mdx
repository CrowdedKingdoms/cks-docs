List the immutable published versions of a listing, newest first. Requires 'view&#x005F;compute&#x005F;diagnostics'. Versions expose artifact hashes and the derived capability summary — never source.


```graphql
appPlayerCodeListingVersions(
  appId: BigInt!
  listingId: String!
): [PlayerCodeVersion!]!
```
