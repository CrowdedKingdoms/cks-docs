Browse an app's active marketplace code listings (free mode). Each listing carries its admission standing: in allow&#x005F;list apps a PENDING listing can be acquired but not installed. Closed-source listings expose artifact hashes and the derived capability summary only — never source.


```graphql
playerCodeListings(
  appId: BigInt!
): [PlayerCodeListing!]!
```
