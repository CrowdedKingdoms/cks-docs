Read the permission keys a grid grants every player with active access to the app (an open build area, a public arena). An empty list means the grid is not open. Requires app-admin ('manage&#x005F;apps').


```graphql
gridOpenPermissions(
  appId: BigInt!
  gridId: BigInt!
): GridOpenPermissions!
```
