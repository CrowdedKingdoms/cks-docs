Operator only (is&#x005F;operator). Everything this API knows about whether an address can be emailed: its stored status, whether its domain is suppressed, and the recent SES events for it (the `send` written when the message was handed to SES, and the `delivery` / `bounce` / `complaint` that came back on the SNS webhook).


```graphql
emailDeliverability(
  email: String!
  eventLimit: Int = 20
): EmailDeliverability!
```
