List executions of player modules on a grid the caller currently owns, newest first. Every run is attributed to the grid owner it executed as; author identity never appears here.


```graphql
playerComputeRuns(
  appId: BigInt!
  gridId: BigInt!
  moduleName: String
  success: Boolean
  limit: Int
  offset: Int
): [PlayerWasmModuleRun!]!
```
