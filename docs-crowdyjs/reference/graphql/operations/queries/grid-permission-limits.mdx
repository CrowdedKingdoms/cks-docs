Read the permission-key whitelist configured for a grid. An empty list means there is no limit (every active runtime permission may be granted on the grid). Requires app-admin ('manage&#x005F;apps').


```graphql
gridPermissionLimits(
  appId: BigInt!
  gridId: BigInt!
): GridPermissionLimits!
```
