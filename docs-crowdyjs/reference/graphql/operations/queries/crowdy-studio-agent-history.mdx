Replay ordered durable typed events with seq greater than afterSeq. Requires the app-scoped owner and use&#x005F;studio&#x005F;agent. Use this query to fill subscription gaps; results are ascending, at-least-once safe, default 100, maximum 200.


```graphql
crowdyStudioAgentHistory(
  sessionId: String!
  afterSeq: BigInt
  first: Int
): AgentEventConnection!
```
