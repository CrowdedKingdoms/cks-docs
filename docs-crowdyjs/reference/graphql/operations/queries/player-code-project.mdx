Load one private Mod Studio project with all bounded source files. Requires an app-scoped token for appId and exact caller ownership; missing, cross-app, and cross-user ids all return the same NOT&#x005F;FOUND shape. Grid owners and studio operators receive no source override.


```graphql
playerCodeProject(
  appId: BigInt!
  projectId: String!
): PlayerCodeProject!
```
