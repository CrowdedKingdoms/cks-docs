Linear end-of-month egress projection for one shared app from calendar-month usage so far. Requires at least 3 elapsed days in the month before returning projected values. Requires the 'view&#x005F;usage' org permission.


```graphql
appUsageProjection(
  orgId: BigInt!
  appId: BigInt!
): AppUsageProjection!
```
