Replay durable events with seq greater than afterSeq, then tail newly committed facts using database replay plus in-memory wakeups. Requires an app-scoped owner, use&#x005F;studio&#x005F;agent, and exact current clientEpoch. Delivery is ordered and at-least-once: deduplicate eventId/seq, fill gaps with crowdyStudioAgentHistory, and acknowledge only contiguous sequences.


```graphql
crowdyStudioAgentEvents(
  sessionId: String!
  afterSeq: BigInt!
  clientEpoch: BigInt!
): CrowdyStudioAgentEvent!
```
