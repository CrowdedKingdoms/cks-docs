# GraphQL schema reference (SDK union schema)

CrowdyJS checks in a **`schema.gql`** file that merges the portions of Management + Game schemas
represented by codegen. Generated docs help compare operation coverage but always defer to each
service’s canonical schema.

Run `npm run graphql:gen` or `npm run build` after refreshing `CrowdyJS/schema.gql`.

Do not hand-edit generated files.
