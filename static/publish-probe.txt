This file exists to answer one question that a green deploy cannot: does each of
the three documentation sites serve the content of ITS OWN branch? All three
branches carry identical pages today, so three sites serving identical bytes is
consistent both with the design working and with all three being fed from one
place. A file that exists on exactly one branch is what tells them apart.

It is landed on dev, published to docs.dev.crowdedkingdoms.com by a dev/vX.Y.Z
tag, and removed by the next dev tag. It must never be promoted to test or prod.
