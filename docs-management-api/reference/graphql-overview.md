# GraphQL schema reference

Browse **reference/graphql/** in the sidebar for every type, query, mutation, and input documented for the Management API.

This schema covers the **management database** only: identity, org RBAC, marketplace, billing, environments, and entitlements (`app_user_access`, tier `permissionKeys`). It does **not** include grid studio operations (`createGrid`, `grantGridPermissions`, …) — those are on the [Game API schema reference](/game-api/reference/graphql-overview).
