Answers to the project profile. An omitted field keeps its answer; null clears it. Complete when every answer but anythingElse is in; startingFromScratch true answers the networking question.


```graphql
input SetOrgProjectProfileInput {
  orgId: BigInt!
  whatBuilding: String
  worldShape: ProjectWorldShape
  playersPerWorldLaunch: Int
  agentsPerWorldLaunch: Int
  playersInViewLaunch: Int
  playersPerWorldYear1: Int
  agentsPerWorldYear1: Int
  playersInViewYear1: Int
  stage: ProjectStage
  launchDate: DateTime
  engine: String
  logicLocation: ProjectLogicLocation
  currentNetworking: String
  currentNetworkingMonthlyCostCents: Int
  startingFromScratch: Boolean
  referenceConsent: Boolean
  anythingElse: String
}
```
