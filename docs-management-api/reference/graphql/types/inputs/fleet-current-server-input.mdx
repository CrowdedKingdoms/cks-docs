The realtime server a fleet session is connected to, named by the address the session connected to and its port. Give ip4 or ip6, the one the session connected to. Giving both, or neither, is refused BAD&#x005F;REQUEST.


```graphql
input FleetCurrentServerInput {
  ip4: String
  ip6: String
  clientPort: Int!
}
```
