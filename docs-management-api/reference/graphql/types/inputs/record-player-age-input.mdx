A player’s birth date, country and (under 18) parental agreement. Kept as the year and month only.


```graphql
input RecordPlayerAgeInput {
  birthDate: String!
  country: String!
  parentalConfirmation: Boolean
}
```

Birth date, YYYY-MM-DD (YYYY-MM is accepted too). Only the year and month are kept, and the age is counted from the last day of that month.

The country the player lives in: ISO 3166-1 alpha-2, such as US.


#### [<code style={{ fontWeight: 'normal' }}>RecordPlayerAgeInput.<b>parentalConfirmation</b></code>](#parental-confirmation)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary " text="scalar"/> {/* #parental-confirmation */}
