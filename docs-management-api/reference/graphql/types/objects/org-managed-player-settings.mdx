An organization's org-managed player settings, and where it stands on the Org-Managed Players Addendum. A Crowded Kingdoms operator sets the settings; an admin of the organization accepts the addendum.


```graphql
type OrgManagedPlayerSettings {
  orgId: BigInt!
  enabled: Boolean!
  maxPlayers: BigInt!
  playerCount: BigInt!
  mintsPerMinute: Int!
  defaultSessionTtlSeconds: Int!
  maxSessionTtlSeconds: Int!
  termsVersion: String!
  termsUrl: String!
  termsAccepted: Boolean!
  termsAcceptedVersion: String
  termsAcceptedAt: DateTime
  termsAcceptedByUserId: BigInt
  viewerMayAcceptTerms: Boolean!
}
```
