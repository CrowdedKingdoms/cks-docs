A federated / passwordless sign-in identity linked to a user account (a social provider, an emailed magic link, or the dev bypass).


```graphql
type UserIdentity {
  identityId: ID!
  userId: ID!
  provider: String!
  subject: String!
  email: String
  emailVerified: Boolean!
  createdAt: DateTime!
  lastLoginAt: DateTime
}
```
