A user's entitlement to a specific app: whether (and via which tier) they may access it. At most one row per (app, user).


```graphql
type AppUserAccess {
  appUserAccessId: BigInt!
  appId: BigInt!
  userId: BigInt!
  tierId: BigInt
  status: String!
  grantedBy: String!
  subscriptionId: String
  expiresAt: DateTime
  createdAt: DateTime!
  updatedAt: DateTime!
  user: User
  tier: AppAccessTier
}
```
