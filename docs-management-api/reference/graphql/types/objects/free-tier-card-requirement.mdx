The free-tier card requirement on this tier. Once it has started (requiredFrom), an organization's apps run only while the organization has a saved card (saving one charges nothing) or an exemption, whatever its wallet holds; otherwise they are paused with runtimeDenialReason payment&#x005F;method&#x005F;required. Every organization runs without a card for newOrganizationGraceDays from its creation, and one created before requiredFrom for existingOrganizationGraceDays from requiredFrom if that is later. Organizations only; player wallets are not asked.


```graphql
type FreeTierCardRequirement {
  requiredFrom: DateTime
  requiredNow: Boolean!
  existingOrganizationGraceDays: Int!
  newOrganizationGraceDays: Int!
}
```
