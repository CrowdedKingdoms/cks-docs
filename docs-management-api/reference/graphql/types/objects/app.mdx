A publishable application (game/experience) owned by an organization. Its discoverability is controlled by visibility and its lifecycle by status.


```graphql
type App {
  appId: BigInt!
  orgId: BigInt!
  name: String!
  slug: String
  description: String
  visibility: AppVisibility!
  status: AppStatus!
  launchUrl: String
  isTrusted: Boolean!
  redirectUris: [String!]!
  clientType: String!
  metadata: String
  state: String
  createdBy: BigInt!
  splitMode: Boolean!
  gameApiUrl: String
  deploymentTarget: String!
  reservedEgressBytesPerSec: BigInt!
  runtimeStatus: String!
  runtimeDenialReason: String
  codeAdmissionMode: String!
  gridClaimPolicy: String!
  gridClaimApproverUserIds: [String!]!
  createdAt: DateTime!
  updatedAt: DateTime!
  org: Organization
}
```
