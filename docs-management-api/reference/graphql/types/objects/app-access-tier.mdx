A free or purchasable access tier for an app, bundling a price and the set of runtime permission keys that granted users receive.


```graphql
type AppAccessTier {
  tierId: BigInt!
  appId: BigInt!
  name: String!
  tierOrder: Float!
  isFree: Boolean!
  isDefault: Boolean!
  priceCents: BigInt
  currency: String
  billingPeriod: String
  description: String
  permissionKeys: [String!]!
  status: String!
  createdAt: DateTime!
  updatedAt: DateTime!
}
```
