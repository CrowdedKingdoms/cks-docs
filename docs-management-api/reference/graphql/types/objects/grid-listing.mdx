A studio grid listing (07 §1.1): a blueprint that stamps a fresh grid per sale, or a concrete grid. Purchase confers grid&#x005F;ownership + the listed keys + quota preset atomically.


```graphql
type GridListing {
  gridListingId: String!
  appId: BigInt!
  kind: String!
  name: String!
  description: String!
  priceCents: Int!
  conferredPermissionKeys: [String!]!
  resalePolicy: String!
  studioCutBps: Int!
  status: String!
}
```
