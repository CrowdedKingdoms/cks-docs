A player’s entitlement to a listing. Free acquisitions write the same row shape paid ones will in P4b (expiry/unit-budget fields exist but stay dormant); uninstall never deletes this row (audit).


```graphql
type PlayerCodeAcquisition {
  acquisitionId: String!
  listingId: String!
  appId: BigInt!
  acquirerUserId: BigInt!
  mode: PlayerCodeAcquisitionMode!
  status: String!
  acquiredAt: DateTime!
  revokedAt: DateTime
}
```
