A single step within a deploy/destroy task. Legacy progress comes from persisted runner rows; DBOS progress is reconstructed from its checkpointed plan and overlays completed checkpoints/audit events. A pending DBOS step is planned work whose exact live state is not yet checkpointed.


```graphql
type CksDeployProgressStep {
  id: String!
  kind: String!
  label: String!
  status: String!
  attempt: Int!
  error: String
```
