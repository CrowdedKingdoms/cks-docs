An active or revoked app code-admission entry. Admission controls execution only; it never grants source access.


```graphql
type AppCodeAdmission {
  admissionId: String!
  appId: BigInt!
  subjectKind: CodeAdmissionSubjectKind!
  subjectRef: String!
  versionRange: String
  admittedBy: BigInt!
  admittedAt: DateTime!
  revokedAt: DateTime
}
```
