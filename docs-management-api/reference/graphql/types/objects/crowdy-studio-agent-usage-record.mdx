One sanitized, platform-funded provider usage record. It contains exact OpenRouter token/cost dimensions but no key, prompt, headers, request/response body, private reasoning, or wallet debit.


```graphql
type CrowdyStudioAgentUsageRecord {
  usageId: String!
  appId: BigInt!
  userId: BigInt!
  sessionId: String!
  runId: String!
  provider: String!
  providerGenerationId: String
  resolvedModelId: String!
  accountingStatus: String!
  requestCount: BigInt!
  promptTokens: BigInt!
  completionTokens: BigInt!
  reasoningTokens: BigInt!
  cachedTokens: BigInt!
  nativePromptTokens: BigInt!
  nativeCompletionTokens: BigInt!
  nativeReasoningTokens: BigInt!
  nativeCachedTokens: BigInt!
  toolCalls: BigInt!
  toolRounds: BigInt!
  compileCount: BigInt!
  wallClockMs: BigInt!
  reservedCostMicrousd: BigInt!
  providerCostUsd: String!
  upstreamInferenceCostUsd: String
  zdrEnforced: Boolean!
  dataCollectionDenied: Boolean!
  platformPolicyRevision: BigInt!
  appPolicyRevision: BigInt!
  billingMode: String!
  payerKind: String!
  occurredAt: DateTime!
  ingestedAt: DateTime!
}
```
