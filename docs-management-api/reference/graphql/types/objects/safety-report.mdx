A report about a player, filed by another player (fileSafetyReport) or by the app’s hub (the node API’s safety.report). Moderators (moderate&#x005F;safety on the app) read and decide it.


```graphql
type SafetyReport {
  appId: BigInt!
  reportId: BigInt!
  reporterUserId: BigInt!
  reportedUserId: BigInt!
  reportedActorUuid: String
  reason: SafetyReportReason!
  details: String
  occurredAt: DateTime!
  filedAt: DateTime!
  status: SafetyReportStatus!
  outcome: String
  resolvedBy: BigInt
  resolvedAt: DateTime
  ncmecReportId: String
  ncmecSubmittedAt: DateTime
  holdId: BigInt
  sessions: [BigInt!]!
  capture: SafetyReportCapture!
}
```
