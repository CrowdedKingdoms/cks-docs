A country Crowded Kingdoms lists: 'blocked' refuses its players (TERRITORY&#x005F;NOT&#x005F;SUPPORTED), and minAge raises the youngest age admitted there. A country not listed is open at the platform's minimum.


```graphql
type TerritoryPolicy {
  countryCode: String!
  status: String!
  minAge: Int!
}
```
