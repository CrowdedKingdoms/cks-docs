A player an organization signs in itself (an org-managed player): a Crowded Kingdoms user with no email, password or wallet, known to the org by its own id.


```graphql
type ManagedPlayer {
  userId: BigInt!
  orgId: BigInt!
  externalId: String!
  gamertag: String
  disambiguation: String
  disabled: Boolean!
  createdAt: DateTime!
}
```
