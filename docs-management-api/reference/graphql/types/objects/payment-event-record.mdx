A single inbound payment-provider webhook event from the reconciliation audit log.


```graphql
type PaymentEventRecord {
  eventId: BigInt!
  provider: PaymentProvider!
  externalEventId: String!
  eventType: String!
  checkoutId: BigInt
  processedAt: DateTime
  error: String
  createdAt: DateTime!
}
```
