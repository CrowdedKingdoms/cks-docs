One priced dimension of the public rate card: its rate and its free allowances. A dimension with a price of 0 is metered but not charged.


```graphql
type PublicRateCardEntryType {
  scope: RateScope!
  metric: String!
  unitLabel: String!
  unitQuantity: BigInt!
  priceCents: Float!
  currency: String!
  freePerHour: BigInt
  freePerMonth: BigInt
}
```
