Human-selected Agentic Crowdy Studio mode. Policy can remove modes but cannot add authority or let the model select one.


```graphql
enum CrowdyStudioAgentMode {
  ASK
  BUILD
  PLAY
}
```


### Values

#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentMode.<b>ASK</b></code>](#ask) \{#ask\} 
Read-only assistance and proposals.


#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentMode.<b>BUILD</b></code>](#build) \{#build\} 
Routine project edits and draft tests under ordinary write/run permissions.


#### [<code style={{ fontWeight: 'normal' }}>CrowdyStudioAgentMode.<b>PLAY</b></code>](#play) \{#play\} 
Game control only while a human-granted, scoped, time-boxed control lease is active.
