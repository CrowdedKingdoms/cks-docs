How a player claim confers grid ownership in an app (D4): SELF&#x005F;CLAIM (the claim right alone assigns ownership server-side; default), APPROVAL (claims create requests that designated approvers accept), INVITE (ownership only against a standing invite), or MARKETPLACE&#x005F;ONLY (only a marketplace grid purchase confers ownership; the purchase edge ships in P4b, so direct claims are refused).


```graphql
enum GridClaimPolicy {
  SELF_CLAIM
  APPROVAL
  INVITE
  MARKETPLACE_ONLY
}
```
