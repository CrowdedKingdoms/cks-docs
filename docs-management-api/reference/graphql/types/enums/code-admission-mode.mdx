Controls player-code censorship for an app. IMPLICIT&#x005F;ALLOW admits lawful code by default; ALLOW&#x005F;LIST requires every code target, including self-authored code, to match an active code/author/org admission.


```graphql
enum CodeAdmissionMode {
  IMPLICIT_ALLOW
  ALLOW_LIST
}
```
