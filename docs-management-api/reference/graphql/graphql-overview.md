# GraphQL schema reference

Pages under `reference/graphql/` are **generated** from the checked-in `schema.gql` file in
the sibling service repository. Run `npm run graphql:gen` (or `npm run build`, which runs it
via `prebuild`) after schema changes to refresh the Markdown.

Do not hand-edit generated files—your changes will be overwritten on the next generation pass.
