Admin view of the user access records for an app (who has been granted/revoked access and on which tier). Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app; super admins bypass. Ordered by most recently updated. Relay cursor connection; prefer this over the offset-based appUserAccessByApp.


```graphql
appUserAccessConnection(
  appId: BigInt!
  first: Int
  after: String
  status: String
): AppUserAccessConnection!
```
