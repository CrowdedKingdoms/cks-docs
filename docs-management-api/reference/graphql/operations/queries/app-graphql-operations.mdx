Top GraphQL operations for an app ranked by bytes over the time range. Read-only reporting; the app must be linked to an environment in the org. Requires the 'view&#x005F;usage' org permission.


```graphql
appGraphqlOperations(
  orgId: BigInt!
  appId: BigInt!
  since: DateTime!
  limit: Int = 20
): [GraphqlOperationUsageRow!]!
```
