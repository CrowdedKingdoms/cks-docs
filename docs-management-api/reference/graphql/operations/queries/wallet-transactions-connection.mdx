Lists the organization's wallet transactions (credits and debits), ordered newest first. Use it to audit how the balance changed over time. Requires the 'view&#x005F;billing' org permission. Relay cursor connection; prefer this over the offset-based walletTransactions.


```graphql
walletTransactionsConnection(
  orgId: BigInt!
  first: Int
  after: String
): WalletTransactionsConnection!
```
