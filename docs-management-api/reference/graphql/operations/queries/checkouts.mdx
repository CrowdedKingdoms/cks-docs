Cross-tenant payments audit across all users, orgs, and apps (newest first), with optional filtering. Restricted to super admins; requests from non-super-admins are rejected. For a caller's own history use `myCheckouts` instead.


```graphql
checkouts(
  filter: CheckoutFilterInput
  limit: Int = 50
  offset: Int = 0
): CheckoutsPage!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>checkouts.<b>filter</b></code>](#filter)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>CheckoutFilterInput</b></code>](/reference/graphql/types/inputs/checkout-filter-input.mdx) <Badge class="badge badge--secondary " text="input"/> \{#filter\}
Optional filters (provider, purpose, status, userId, orgId, appId), AND-combined. Omit to return all checkouts.


#### [<code style={{ fontWeight: 'normal' }}>checkouts.<b>limit</b></code>](#limit)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary badge--deprecated" text="deprecated"/> <Badge class="badge badge--secondary " text="scalar"/> \{#limit\}
:::warning[DEPRECATED]

Use checkoutsConnection(first:, after:) instead. See /overview/pagination.

:::

Maximum number of checkouts to return. Default 50; clamped to the range 1-200.


#### [<code style={{ fontWeight: 'normal' }}>checkouts.<b>offset</b></code>](#offset)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary badge--deprecated" text="deprecated"/> <Badge class="badge badge--secondary " text="scalar"/> \{#offset\}
:::warning[DEPRECATED]

Use checkoutsConnection(first:, after:) instead. See /overview/pagination.

:::

Number of checkouts to skip for offset/limit pagination. Default 0; negative values are treated as 0.
