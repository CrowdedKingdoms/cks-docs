Browse the app's grid listings (P4b): blueprints that stamp a fresh grid per purchase, or concrete grids. Buying confers ownership + keys + quota preset atomically.


```graphql
gridListings(
  appId: BigInt!
): [GridListing!]!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GridListing</b></code>](/reference/graphql/types/objects/grid-listing.mdx) <Badge class="badge badge--secondary " text="object"/>
