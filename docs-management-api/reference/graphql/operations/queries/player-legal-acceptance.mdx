Whether the signed-in account has stored the platform's current player documents (playerLegalDocuments) and, with appId, the app's own (appRequiredDocuments); while the platform still asks for it, the age-of-majority attestation or a birth date too. False means createPortalAuthorizationCode and mintAppToken will refuse with LEGAL&#x005F;ACCEPTANCE&#x005F;REQUIRED until recordPlayerConsents. Requires a session token.


```graphql
playerLegalAcceptance(
  appId: BigInt
): Boolean!
```
