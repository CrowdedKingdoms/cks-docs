Lists the org's saved (vaulted) off-session payment methods. Returns metadata only (brand/last4/status), never card numbers. Requires the 'view&#x005F;billing' org permission.


```graphql
orgPaymentMethods(
  orgId: BigInt!
): [SavedPaymentMethod!]!
```
