Full detail for one environment: the environment row plus components, change orders, audit log, secrets, outputs, billing resources, live deploy/destroy progress, and Buddy UDP health. Returns null when no environment with that slug exists for the org. Requires the 'view&#x005F;environments' org permission.


```graphql
orgEnvironment(
  orgId: BigInt!
  slug: String!
): CksEnvironmentDetail
```
