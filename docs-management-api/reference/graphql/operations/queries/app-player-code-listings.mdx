List an app's marketplace code listings (studio administration view), newest first. Requires 'view&#x005F;compute&#x005F;diagnostics'. includeDelisted adds delisted/killed rows for moderation history.


```graphql
appPlayerCodeListings(
  appId: BigInt!
  includeDelisted: Boolean = false
): [PlayerCodeListing!]!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerCodeListing</b></code>](/reference/graphql/types/objects/player-code-listing.mdx) <Badge class="badge badge--secondary " text="object"/>
