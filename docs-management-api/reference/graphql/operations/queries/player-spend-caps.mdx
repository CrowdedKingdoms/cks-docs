### Type

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerSpendCap</b></code>](/reference/graphql/types/objects/player-spend-cap.mdx) <Badge class="badge badge--secondary " text="object"/>
A player's self-set spend cap (06 §2a): a daily/monthly ceiling globally or per app. The effective runtime limit is min(developer policy, self-cap, wallet balance); hitting a cap pauses that player's mods with PLAYER&#x005F;SPEND&#x005F;CAP, never their play.
