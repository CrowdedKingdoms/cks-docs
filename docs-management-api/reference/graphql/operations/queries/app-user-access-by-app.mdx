Admin view of the user access records for an app (who has been granted/revoked access and on which tier). Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app; super admins bypass. Ordered by most recently updated. Paginated via limit/offset.


```graphql
appUserAccessByApp(
  appId: BigInt!
  status: String
  limit: Int = 50
  offset: Int = 0
): [AppUserAccess!]!
```
