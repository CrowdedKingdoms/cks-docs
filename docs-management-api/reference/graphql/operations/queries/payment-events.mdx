Audit log of inbound payment-provider webhook events (used for idempotent reconciliation of checkouts), newest first. Restricted to super admins; requests from non-super-admins are rejected.


```graphql
paymentEvents(
  limit: Int = 50
  offset: Int = 0
): PaymentEventsPage!
```

#### [<code style={{ fontWeight: 'normal' }}>paymentEvents.<b>limit</b></code>](#limit)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary badge--deprecated" text="deprecated"/> <Badge class="badge badge--secondary " text="scalar"/> \{#limit\} 
:::warning[DEPRECATED]

Use paymentEventsConnection(first:, after:) instead. See /overview/pagination.

:::

Maximum number of events to return. Default 50; clamped to the range 1-200.


#### [<code style={{ fontWeight: 'normal' }}>paymentEvents.<b>offset</b></code>](#offset)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary badge--deprecated" text="deprecated"/> <Badge class="badge badge--secondary " text="scalar"/> \{#offset\} 
:::warning[DEPRECATED]

Use paymentEventsConnection(first:, after:) instead. See /overview/pagination.

:::

Number of events to skip for offset/limit pagination. Default 0; negative values are treated as 0.
