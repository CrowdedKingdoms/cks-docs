Org-level rollup of replication/GraphQL byte totals and GraphQL op counts across all apps in the organization for the time window. Read-only reporting. Requires the 'view&#x005F;usage' org permission.


```graphql
orgUsageSummary(
  orgId: BigInt!
  since: DateTime
): OrgUsageSummary!
```
