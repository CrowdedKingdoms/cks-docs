Release versions a specific environment may upgrade to: available, deployable by its environment class, and not older than the version it currently runs (forward-only — no rollback). Newest first; backs the version picker passed to redeployEnvironment. Requires the 'view&#x005F;environments' org permission.


```graphql
environmentForwardVersions(
  orgId: BigInt!
  slug: String!
): [CksEnvironmentVersion!]!
```
