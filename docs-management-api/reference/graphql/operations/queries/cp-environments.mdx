Operator only (is&#x005F;operator). Paginated list of all environments across every org. Returns a &#x002A;Page (rows/total/page/pageSize); page is 1-based.


```graphql
cpEnvironments(
  page: Int! = 1
  pageSize: Int! = 50
): CpAdminEnvironmentsPage!
```
