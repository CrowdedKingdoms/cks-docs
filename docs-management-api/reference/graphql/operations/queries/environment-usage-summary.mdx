Per-minute replication and GraphQL byte/message usage time series for the apps linked to an environment, plus replication rate peaks and live Buddy rates. Read-only observability. Requires the 'view&#x005F;usage' org permission.


```graphql
environmentUsageSummary(
  orgId: BigInt!
  environmentSlug: String!
  since: DateTime!
): EnvironmentUsageSummary!
```
