Dev only. The organization's managed players, by user id. `search` matches the start of the external id (exactly) or of the gamertag (any case). An org token with players:manage, or an org admin with manage&#x005F;players.


```graphql
managedPlayers(
  orgId: BigInt!
  search: String
  first: Int
  after: String
): ManagedPlayersPage!
```
