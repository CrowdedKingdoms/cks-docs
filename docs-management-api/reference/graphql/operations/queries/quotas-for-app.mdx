Lists the app-scoped quota rules explicitly configured for an app (excludes org-, tier-, and free-tier-default quotas). Use `effectiveQuota` to resolve the limit actually applied for a given metric. Requires the 'view&#x005F;usage' app permission.


```graphql
quotasForApp(
  appId: BigInt!
): [ServiceQuota!]!
```
