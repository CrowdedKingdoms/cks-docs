Aggregate replication/GraphQL byte totals per environment across the org for the time window. Read-only reporting. Requires the 'view&#x005F;usage' org permission.


```graphql
orgUsageByEnvironment(
  orgId: BigInt!
  since: DateTime!
): [EnvironmentUsageRollupRow!]!
```

Organization id (BigInt) to roll up usage for.

Start of the aggregation window (ISO-8601 DateTime or relative duration such as 1d, 7d, 1h) up to now.
