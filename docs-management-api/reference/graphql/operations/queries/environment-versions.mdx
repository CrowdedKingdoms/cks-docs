Catalog of available environment release versions that can be deployed, newest first. Not org-scoped (any authenticated caller). For the versions a specific environment may move to, use environmentForwardVersions.


```graphql
environmentVersions: [CksEnvironmentVersion!]!
```

#### [<code style={{ fontWeight: 'normal' }}><b>CksEnvironmentVersion</b></code>](/reference/graphql/types/objects/cks-environment-version.mdx) <Badge class="badge badge--secondary " text="object"/>
