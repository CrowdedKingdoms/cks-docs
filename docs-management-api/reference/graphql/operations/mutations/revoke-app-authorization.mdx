Revoke a previously-granted app authorization and immediately revoke the user's live app tokens for it. Requires a SESSION token.


```graphql
revokeAppAuthorization(
  appId: BigInt!
): Boolean!
```

#### [<code style={{ fontWeight: 'normal' }}>revokeAppAuthorization.<b>appId</b></code>](#app-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#app-id\}
Numeric id of the app whose authorization (consent grant) to revoke (BigInt as a decimal string).
