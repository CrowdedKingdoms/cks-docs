Removes a saved (vaulted) off-session payment method from the org; returns true on success. If it was the method backing auto-billing, recharges will fail until another is set up. Requires the 'manage&#x005F;billing' org permission.


```graphql
removeSharedPaymentMethod(
  orgId: BigInt!
  paymentMethodId: BigInt!
  idempotencyKey: String
): Boolean!
```
