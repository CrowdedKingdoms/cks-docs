Super-admin only. Sets the per-user early-access override (users.grant&#x005F;early&#x005F;access&#x005F;override), force-enabling early-access entitlement for the target regardless of the global early-access window. Requires the caller to be a super admin.


```graphql
setEarlyAccessOverride(
  userId: BigInt!
  value: Boolean!
): User!
```
