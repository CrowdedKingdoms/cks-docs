Removes a user from an organization. Requires the 'manage&#x005F;members' permission on the org (super admins bypass). DESTRUCTIVE: revokes the user's membership and role assignments in that org. Returns false if the user was not a member.


```graphql
removeOrgMember(
  orgId: BigInt!
  userId: BigInt!
  idempotencyKey: String
): Boolean!
```
