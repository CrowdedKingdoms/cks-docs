Rename a managed player, or disable or enable it. Disabling ends every session it has now (realtime and ck-exec included) and refuses its sign-ins; enabling lifts only a disable the org set. An org token with players:manage, or an org admin with manage&#x005F;players.

```graphql
updateManagedPlayer(
  input: UpdateManagedPlayerInput!
): ManagedPlayer!
```
