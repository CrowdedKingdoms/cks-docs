Deletes an organization role. Requires the 'manage&#x005F;members' permission on the role's org (super admins bypass). DESTRUCTIVE: removes the role and unassigns it from all members. Returns false if the role does not exist.


```graphql
deleteOrgRole(
  orgRoleId: BigInt!
  idempotencyKey: String
): Boolean!
```
