Operator only (is&#x005F;operator). Yanks (withdraws) an environment version so it can no longer be deployed; existing environments are unaffected. Writes an audit entry. Returns true on success.


```graphql
yankEnvironmentVersion(
  version: String!
): Boolean!
```
