Store acceptance of the platform's current player documents (playerLegalDocuments) and, with appId, of the app's own (appRequiredDocuments), recorded with the app and the method. acceptLegal must be true. attestAgeOfMajority must be true too while the platform still uses the age-of-majority attestation (the player then counts as 18 or older); once players give a birth date instead (recordPlayerAge) it is ignored. A refused call stores nothing (LEGAL&#x005F;ACCEPTANCE&#x005F;REQUIRED). Idempotent for a version already stored. Requires a session token. Gameplay tokens stay refused until this has succeeded for the current documents.


```graphql
recordPlayerConsents(
  acceptLegal: Boolean!
  attestAgeOfMajority: Boolean
  appId: BigInt
  method: LegalAcceptanceMethod
): Boolean!
```

True when the player agrees to the current required legal documents.


#### [<code style={{ fontWeight: 'normal' }}>recordPlayerConsents.<b>attestAgeOfMajority</b></code>](#attest-age-of-majority)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary " text="scalar"/> {/* #attest-age-of-majority */} 
True when the player attests they are at least 18, or the age of majority where they live if that is higher. Required while the platform uses the attestation; ignored once it asks for a birth date.
