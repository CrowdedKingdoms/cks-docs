Begin vaulting a card on the caller's player wallet (P4b): returns a Stripe SetupIntent client secret + publishable key for the browser to confirm. On success the card is saved for wallet auto-recharge and rent auto-renew. Closes the P2 gap where players had no card-setup path.


```graphql
beginPlayerCardSetup: PlayerCardSetup!
```


### Type

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerCardSetup</b></code>](/reference/graphql/types/objects/player-card-setup.mdx) <Badge class="badge badge--secondary " text="object"/> 
A pending player card-vault (P4b): the Stripe SetupIntent the browser confirms to save a card off-session, enabling wallet auto-recharge and rent auto-renew. On success a setup&#x005F;intent.succeeded webhook persists the card.
