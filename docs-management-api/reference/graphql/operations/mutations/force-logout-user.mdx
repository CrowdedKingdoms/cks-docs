Super-admin only. Revokes every active session for the target user (deletes their game&#x005F;tokens and records revocations so split-mode caches evict them immediately). Requires the caller to be a super admin. SIDE EFFECT: the target is signed out on all devices.


```graphql
forceLogoutUser(
  userId: BigInt!
): Boolean!
```
