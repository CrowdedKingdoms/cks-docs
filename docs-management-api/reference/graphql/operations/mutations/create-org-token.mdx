Mints a new org API token and returns the plaintext token exactly once - save it, since subsequent queries only show metadata. Requires the 'manage&#x005F;tokens' permission on the target org (super admins bypass).


```graphql
createOrgToken(
  input: CreateOrgTokenInput!
): OrgTokenWithSecret!
```
