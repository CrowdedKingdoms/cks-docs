Updates a dedicated environment's autoscaling bounds (game-api / Buddy min & max server counts), load-balancer count, and optionally the Caddy flavor, queuing a change order that redeploys the affected tiers. May change the hourly cost. Rejected for 'dev&#x005F;single' environments and when another change order is already active. Requires the 'manage&#x005F;environments' org permission.


```graphql
updateEnvironmentScaling(
  input: UpdateEnvironmentScalingInput!
): CksEnvironmentChangeOrder!
```
