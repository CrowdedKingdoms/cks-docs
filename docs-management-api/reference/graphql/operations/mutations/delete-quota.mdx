Permanently deletes a quota enforcement rule by id. Returns true if a rule was removed, or false if no quota with that id exists. Destructive and not reversible: once removed, the metric falls back to the next-most-specific rule or the free-tier default. Requires the 'manage&#x005F;quotas' permission on the same scope (app or org) the quota belongs to, or super admin for global quotas.


```graphql
deleteQuota(
  quotaId: BigInt!
  idempotencyKey: String
): Boolean!
```
