Operator only (is&#x005F;operator). Creates or overwrites a control-plane secret (encrypted at rest) and writes an audit entry. SENSITIVE: plaintext is write-only and never returned by cpSecrets.


```graphql
putCpSecret(
  environmentId: String!
  name: String!
  plaintext: String!
  kind: String
): CpSecretRow!
```
