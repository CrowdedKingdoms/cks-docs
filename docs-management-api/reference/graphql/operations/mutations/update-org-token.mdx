Updates an org token's metadata (label, expiry, active flag). Requires the 'manage&#x005F;tokens' permission on the token's org (super admins bypass). Does not rotate the secret value.


```graphql
updateOrgToken(
  orgTokenId: BigInt!
  input: UpdateOrgTokenInput!
): OrgToken!
```
