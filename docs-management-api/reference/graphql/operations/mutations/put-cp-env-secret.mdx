Operator only (is&#x005F;operator). Creates or overwrites an environment-delivered secret (injected into the tenant runtime) and writes an audit entry. SENSITIVE: plaintext is write-only and never returned.


```graphql
putCpEnvSecret(
  environmentId: String!
  name: String!
  plaintext: String!
  kind: String
): CpEnvSecretRow!
```
