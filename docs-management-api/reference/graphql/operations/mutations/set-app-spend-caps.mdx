Sets per-app hourly/daily spend caps (in cents) and returns the re-evaluated runtime state. Pass null for a limit to clear that cap. Exceeding a cap denies the app's runtime (runtimeDenialReason = spend&#x005F;cap). Requires the 'manage&#x005F;billing' permission on the app's org.


```graphql
setAppSpendCaps(
  appId: BigInt!
  hourlyLimitCents: BigInt
  dailyLimitCents: BigInt
): AppRuntimeState!
```
