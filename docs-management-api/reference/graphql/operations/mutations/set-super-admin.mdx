Super-admin only. Grants or revokes platform super-admin (users.is&#x005F;super&#x005F;admin), which bypasses every org permission check platform-wide. Requires the caller to be a super admin. SIDE EFFECT: changes the target user's platform privileges.


```graphql
setSuperAdmin(
  userId: BigInt!
  value: Boolean!
): User!
```
