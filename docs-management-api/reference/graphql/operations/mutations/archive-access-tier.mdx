Soft-delete an access tier by setting its status to 'archived' (the row is retained, NOT hard-deleted) and notifies the game API. Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app that owns the tier; super admins bypass. Existing user grants on this tier are NOT automatically revoked. Throws if the tier is not found.


```graphql
archiveAccessTier(
  tierId: BigInt!
  idempotencyKey: String
): AppAccessTier!
```

Numeric id of the access tier to archive (soft delete).
