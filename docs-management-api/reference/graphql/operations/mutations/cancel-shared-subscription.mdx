DESTRUCTIVE. Cancels an app's paid shared-environment subscription. The app loses its paid shared slot (typically at currentPeriodEnd) and may be denied runtime once the period lapses unless a free slot covers it. Returns the updated subscription. Requires the 'manage&#x005F;billing' permission on the app's org.


```graphql
cancelSharedSubscription(
  appId: BigInt!
  idempotencyKey: String
): AppSharedSubscription!
```
