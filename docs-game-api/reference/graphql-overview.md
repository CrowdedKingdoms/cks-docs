# GraphQL schema reference

Browse **reference/graphql/** in the sidebar for every type, query, mutation, and input documented for the Game API.

Includes **studio grid** mutations (`createGrid`, `grantGridPermissions`, …) and runtime world operations (chunks, voxels, actors, UDP proxy). Identity, billing, and tier grants are on the [Management API schema reference](/management-api/reference/graphql-overview).

See **[Grids and permissions](/game-api/grids-and-permissions)** for how management entitlements and game-side grid grants interact.
