Input for sending a text message (chat) to the UDP game server. The text will be broadcast to nearby players in the same chunk.


```graphql
input ClientTextPacketInput {
  appId: BigInt!
  chunk: ChunkCoordinatesInput!
  uuid: String!
  text: String!
  distance: Int
  decayRate: Int
  sequenceNumber: Int
}
```
