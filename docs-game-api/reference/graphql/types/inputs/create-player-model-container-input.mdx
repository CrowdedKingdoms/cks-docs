Create a flexible player-owned model container inside one grid. The caller must currently own the grid; owner identity cannot be supplied.


```graphql
input CreatePlayerModelContainerInput {
  appId: BigInt!
  gridId: BigInt!
  typeKey: String
  displayName: String
  stateJson: String
}
```
