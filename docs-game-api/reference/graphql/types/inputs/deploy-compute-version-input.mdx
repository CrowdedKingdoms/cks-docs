Upload a new immutable source version of a module. The source is validated (size caps, crate allowlist, no build-time code) and parked as compile&#x005F;status=pending until an instance compiles it.


```graphql
input DeployComputeVersionInput {
  appId: BigInt!
  moduleName: String!
  sourceFilesJson: String!
  sdkVersion: String!
  abiVersion: Int!
}
```
