Arguments for getChunk: selects a single chunk by app id and chunk coordinates, with optional LOD filtering.


```graphql
input GetChunkInput {
  appId: BigInt!
  coordinates: ChunkCoordinatesInput!
  requestedLodLevels: [Int!]
  includeAllLods: Boolean
}
```
