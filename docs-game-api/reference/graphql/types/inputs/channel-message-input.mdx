Input for publishing a message to a channel. Delivered to every active member of the channel (regardless of location), not chunk-routed. The sender must have the channel send&#x005F;messages permission.


```graphql
input ChannelMessageInput {
  channelId: BigInt!
  uuid: String!
  payload: String!
  sequenceNumber: Int
}
```
