Create a grid-confined player automation. Trigger and action are strict JSON shapes; owner/app/grid selectors cannot be supplied.


```graphql
input CreatePlayerAutomationInput {
  appId: BigInt!
  gridId: BigInt!
  name: String!
  description: String
  triggerJson: String!
  actionJson: String!
  maxRunsPerMinute: Int
  failureThreshold: Int
  cooldownMs: Int
}
```
