Which organization to retire, proof that you mean that one, and why.


```graphql
input RetireOrganizationInput {
  orgId: BigInt!
  expectedSlug: String!
  reason: String!
  acknowledgeFrozenBalance: Boolean
}
```

#### [<code style={{ fontWeight: 'normal' }}>RetireOrganizationInput.<b>expectedSlug</b></code>](#expected-slug)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String!</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#expected-slug\} 
The slug the organization must currently have. Refused if it does not match, which is what stops a mistyped or copy-pasted id from retiring a paying customer. There is no bulk form of this mutation for the same reason.


#### [<code style={{ fontWeight: 'normal' }}>RetireOrganizationInput.<b>reason</b></code>](#reason)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String!</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#reason\} 
Why this organization is being retired. Required and stored on the tombstone.


#### [<code style={{ fontWeight: 'normal' }}>RetireOrganizationInput.<b>acknowledgeFrozenBalance</b></code>](#acknowledge-frozen-balance)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Boolean</b></code>](/reference/graphql/types/scalars/boolean.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#acknowledge-frozen-balance\} 
Required when the organization holds a non-zero wallet balance. Retirement FREEZES that balance in place; it is not refunded and not forfeited. Refusing by default rather than omitting the case is deliberate — an unreachable dangerous path guarantees the danger and removes the fix.
