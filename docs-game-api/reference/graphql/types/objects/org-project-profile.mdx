The organization's project profile: seven questions, the last optional. Complete and approved by Crowded Kingdoms, it earns the PROFILE free tier level.


```graphql
type OrgProjectProfile {
  orgId: BigInt!
  whatBuilding: String
  worldShape: ProjectWorldShape
  playersPerWorldLaunch: Int
  agentsPerWorldLaunch: Int
  playersInViewLaunch: Int
  playersPerWorldYear1: Int
  agentsPerWorldYear1: Int
  playersInViewYear1: Int
  stage: ProjectStage
  launchDate: DateTime
  engine: String
  logicLocation: ProjectLogicLocation
  currentNetworking: String
  currentNetworkingMonthlyCostCents: Int
  startingFromScratch: Boolean
  referenceConsent: Boolean
  anythingElse: String
  completedAt: DateTime
  status: ProjectProfileStatus!
  reviewedAt: DateTime
  updatedAt: DateTime
}
```
