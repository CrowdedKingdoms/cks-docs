One recorded client session of an app with replay logging on: a game token's inputs, from the first one the realtime servers accepted to the last. Kept for the input log's published retention.


```graphql
type InputLogSession {
  appId: BigInt!
  gameTokenId: BigInt!
  userId: BigInt!
  datacenter: String
  startedAt: DateTime!
  lastSeenAt: DateTime!
  endedAt: DateTime
  endReason: String
  messageCount: BigInt!
  byteCount: BigInt!
  messageTypes: [Int!]!
}
```
