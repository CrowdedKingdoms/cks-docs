A recorded edit to a single voxel (one row of the voxel&#x005F;updates log): the app/chunk/local-position that changed, the new voxel type, an optional state blob, and who/when. Returned by listVoxels, getVoxelList and listVoxelUpdatesByDistance; created by updateVoxel. A background maintenance job later folds these edits into the chunk grid.


```graphql
type Voxel {
  voxelUpdateId: BigInt!
  appId: BigInt!
  coordinates: ChunkCoordinates!
  location: VoxelCoordinates!
  voxelType: Int!
  state: String
  createdBy: BigInt!
  createdAt: DateTime!
}
```
