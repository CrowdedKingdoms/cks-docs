An immutable published version of a code listing: artifact hashes (never source), explicit server-to-client requirements, and the DERIVED capability summary installers consent to.


```graphql
type PlayerCodeListingVersion {
  versionId: String!
  listingId: String!
  versionNo: Int!
  serverArtifactHashes: [String!]!
  clientArtifactHashes: [String!]!
  requirements: [PlayerCodeRequirement!]!
  capabilitySummaryJson: String!
  capabilityHash: String!
  openSource: Boolean!
  licenseText: String
  createdAt: DateTime
}
```
