Typed tool event. JSON fields are descriptor-versioned and validated against the descriptor returned by crowdyStudioAgentToolDescriptors; they are never arbitrary executor input.


```graphql
type AgentToolEvent implements AgentEventBase {
  protocolVersion: String!
  eventId: String!
  sessionId: String!
  seq: BigInt!
  type: CrowdyStudioAgentEventType!
  runId: String
  version: String!
  createdAt: DateTime!
  toolCallId: String!
  toolName: String!
  toolVersion: String!
  status: CrowdyStudioAgentToolCallStatus!
  safeSummary: String
  descriptorDigest: String
  argumentHash: String
  executor: CrowdyStudioAgentToolExecutor
  contextVersion: String
  clientEpoch: BigInt
  argumentsJson: String
  leaseId: String
  approvalGrant: String
  idempotencyKey: String
  resultJson: String
  invocation: AgentToolInvocation
  result: AgentToolResultEnvelope
  error: AgentError
  deadline: DateTime
}
```
