Startup contract for browser game clients. Fetch this after login to initialize protocol/version checks and UDP proxy state in one round trip.


```graphql
type GameClientBootstrap {
  appId: BigInt!
  me: User!
  versionInfo: ServerVersionInfo!
  udpProxyConnectionStatus: UdpProxyConnectionStatus!
  realtimeProtocol: String!
  subscriptionName: String!
  maxReplicationDistance: Int!
  maxDecayRate: Int!
  sequenceNumberModulo: Int!
  binaryRelayEnabled: Boolean!
  binaryRelayPath: String!
  binaryRelayProtocol: String!
  discoveryUrl: String
  gameApiUrl: String
  gameApiWsUrl: String
}
```

#### [<code style={{ fontWeight: 'normal' }}>GameClientBootstrap.<b>discoveryUrl</b></code>](#discovery-url)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#discovery-url\} 
Stable entry point that always resolves to SOME healthy API instance — the environment’s shared load balancer. Use this to RE-DISCOVER an endpoint when the instance you are connected to stops answering: call gameClientBootstrap (or mintAppToken) against it and use the gameApiUrl it returns. This is the recovery path for direct connect, where gameApiUrl is a single instance that can die; discoveryUrl is chosen so that it cannot die with it. Null only if the server has no public URL configured.


#### [<code style={{ fontWeight: 'normal' }}>GameClientBootstrap.<b>gameApiUrl</b></code>](#game-api-url)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#game-api-url\} 
HTTPS origin the client should use for GraphQL right now. Under direct connect this is the specific instance serving you (e.g. https://ck-api-2.…), which is NOT interchangeable with other instances for an open realtime session; otherwise it is the shared load balancer. If requests here start failing, fall back to discoveryUrl.
