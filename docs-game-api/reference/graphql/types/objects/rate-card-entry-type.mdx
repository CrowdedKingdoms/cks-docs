One priced dimension: its rate and, where it has one, its hourly free allowance. A dimension with a price of 0 is metered but not charged.


```graphql
type RateCardEntryType {
  scope: RateScope!
  metric: String!
  unitLabel: String!
  unitQuantity: BigInt!
  priceCents: Float!
  currency: String!
  freePerHour: BigInt
  freePerMonth: BigInt
  description: String
}
```
