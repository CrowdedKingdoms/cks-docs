A mod: a player’s code on a grid they own, run by ck-exec as the hub `mod:<name>` keyed by the grid id, in its owner’s own sandbox (dev-tier preview).


```graphql
type ExecMod {
  modId: String!
  gridId: BigInt!
  name: String!
  ownerId: BigInt!
  version: Int!
  digest: String!
  enabled: Boolean!
  listingId: BigInt
  blocked: String
  running: Boolean!
  updatedAt: DateTime!
}
```
