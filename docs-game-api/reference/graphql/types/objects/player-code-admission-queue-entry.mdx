One row of an app's admission queue: a listing joined with its standing under the app's allow-list (admitted via a matching code, author, or org admission; pending; or revoked). The studio moderation surface for allow&#x005F;list apps.


```graphql
type PlayerCodeAdmissionQueueEntry {
  listing: PlayerCodeListing!
  admissionState: PlayerCodeAdmissionState!
  admissionId: String
  matchedSubjectKind: String
}
```
