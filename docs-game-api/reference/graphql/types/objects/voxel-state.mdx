A single voxel's override on a chunk, stored with it or recorded as a voxel edit: its local position, its voxel type, and an opaque base64-encoded state blob.


```graphql
type VoxelState {
  voxelCoord: VoxelCoordinates!
  voxelType: Int!
  state: String
}
```
