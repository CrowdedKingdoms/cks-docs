A chunk near you was replaced as a whole (a hub's or mod's world.set&#x005F;chunk; Buddy v0.45.0): read it again with getChunk, or getChunksByDistance with since. It comes instead of a voxel update per voxel. Received via the udpNotifications subscription.


```graphql
type ChunkChangedNotification {
  appId: BigInt!
  chunkX: BigInt!
  chunkY: BigInt!
  chunkZ: BigInt!
  distance: Int!
  updatedAtMs: BigInt!
  sequenceNumber: Int!
}
```
