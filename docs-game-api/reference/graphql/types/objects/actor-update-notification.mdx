Notification received when an actor (player or NPC) state is updated by another client or the server. Received via the udpNotifications subscription.


```graphql
type ActorUpdateNotification {
  appId: BigInt!
  chunkX: BigInt!
  chunkY: BigInt!
  chunkZ: BigInt!
  distance: Int!
  decayRate: Int!
  uuid: String!
  state: String!
  sequenceNumber: Int!
  epochMillis: BigInt!
}
```
