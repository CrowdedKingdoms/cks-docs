Whether an app’s ck-exec code may run: its active version and its switches.


```graphql
type ExecAppStatus {
  activeVersion: Int
  disabled: Boolean!
  disabledTypes: [String!]!
  budgetPaused: Boolean!
  budgetPauseReason: String
  maxInstances: Int
  maxReservedMb: Int
  instanceLimit: Int
  instances: Int
  reservedMb: Int
}
```

#### [<code style={{ fontWeight: 'normal' }}>ExecAppStatus.<b>maxInstances</b></code>](#max-instances)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#max-instances\} 
The most instances the app may have placed in this datacenter. The free hub tier (an organization that has not funded the app) allows 16; null means the manager's default.


#### [<code style={{ fontWeight: 'normal' }}>ExecAppStatus.<b>maxReservedMb</b></code>](#max-reserved-mb)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#max-reserved-mb\} 
The most memory, in MB, the app's placed instances may reserve in this datacenter (each instance reserves its type's memory). The free hub tier allows 1,024; null means no memory limit beyond the instance count.

The instance limit in force: maxInstances, or the manager’s default when that is null. Null from a manager older than ck-exec 0.15.

Instances of the app placed and not yet stopped in this datacenter now, mods included. Null from a manager older than ck-exec 0.15.


#### [<code style={{ fontWeight: 'normal' }}>ExecAppStatus.<b>reservedMb</b></code>](#reserved-mb)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#reserved-mb\}
