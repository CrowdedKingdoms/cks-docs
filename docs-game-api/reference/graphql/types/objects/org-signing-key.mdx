The public half of a key an organization signs its players' sign-in assertions with (exchangeManagedPlayerAssertion). Only public keys are stored. Dev only for now.


```graphql
type OrgSigningKey {
  keyId: BigInt!
  orgId: BigInt!
  kid: String!
  algorithm: String!
  publicJwk: String!
  issuer: String!
  audience: String
  appIds: [BigInt!]
  label: String
  createdAt: DateTime!
  revokedAt: DateTime
}
```
