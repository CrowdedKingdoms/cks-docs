A persisted 16x16x16-voxel chunk (4096 voxels) of an app's voxel world. Holds the packed voxel-type grid (`voxels`), sparse per-voxel state overrides (`voxelStates`), an optional opaque chunk-level state blob (`chunkState`), and level-of-detail meshes (`lods`). Returned by getChunk/getChunksByDistance and written by updateChunk/updateChunkState/updateChunkLods.


```graphql
type Chunk {
  chunkId: ID!
  appId: ID!
  coordinates: ChunkCoordinates!
  voxels: String
  voxelStates: [VoxelState!]!
  owner: ID
  createdAt: DateTime!
  updatedAt: DateTime!
  chunkState: String
  cdnUploadedAt: DateTime
  lods: [LodData!]
}
```

BASE64-encoded binary blob of the dense voxel-type grid. When present, the DECODED buffer is exactly 4096 bytes: one unsigned byte (voxel type 0-255) per voxel, indexed as x + y&#x002A;16 + z&#x002A;256 with x,y,z in 0-15. Null when the chunk has no voxel grid yet. Decode from base64 before reading.
