A grid listing available in the app store (P4b): a blueprint that stamps a fresh grid per purchase, or a concrete grid. Buying it confers grid&#x005F;ownership + the listed player-code keys + the quota preset atomically.


```graphql
type GridListing {
  gridListingId: String!
  appId: BigInt!
  kind: String!
  name: String!
  description: String!
  priceCents: Int!
  conferredPermissionKeys: [String!]!
  resalePolicy: String!
}
```
