Notification received when a voxel (block) is updated by another client or the server. Received via the udpNotifications subscription.


```graphql
type VoxelUpdateNotification {
  appId: BigInt!
  chunkX: BigInt!
  chunkY: BigInt!
  chunkZ: BigInt!
  distance: Int!
  decayRate: Int!
  uuid: String!
  voxelX: Int!
  voxelY: Int!
  voxelZ: Int!
  voxelType: Int!
  voxelState: String!
  sequenceNumber: Int!
  epochMillis: BigInt!
}
```
