How a player claim confers grid ownership in this app (D4): SELF&#x005F;CLAIM (the claim alone assigns ownership), APPROVAL (claims create requests designated approvers accept), INVITE (only against a standing invite), or MARKETPLACE&#x005F;ONLY (only a marketplace grid purchase; direct claims refused — the purchase edge ships in P4b).


```graphql
enum GridClaimPolicy {
  SELF_CLAIM
  APPROVAL
  INVITE
  MARKETPLACE_ONLY
}
```
