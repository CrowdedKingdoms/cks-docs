Error codes returned by UDP game servers in response messages. NO&#x005F;ERROR (0) indicates success, all other values indicate various error conditions.


```graphql
enum UdpErrorCode {
  NO_ERROR
  UNKNOWN_ERROR
  EMAIL_NOT_FOUND
  BAD_PASSWORD
  EMAIL_ALREADY_EXISTS
  INVALID_TOKEN
  APP_NOT_FOUND
  UNAUTHORIZED
  APP_NOT_LOADED
  EMAIL_TOO_SHORT
  EMAIL_TOO_LONG
  PASSWORD_TOO_SHORT
  PASSWORD_TOO_LONG
  GAME_TOKEN_WRONG_SIZE
  NAME_TOO_LONG
  INVALID_REQUEST
  EMAIL_INVALID
  INVALID_TOKEN_LENGTH
  INVALID_APP_ID
  CHUNK_NOT_FOUND
  USER_NOT_AUTHENTICATED
  INVALID_STATE_DATA
  USER_NOT_APP_ADMIN
  GRID_OUTSIDE_ASSIGNMENT
  NO_MATCHING_GRID_ASSIGNMENT
  INVALID_GRID_COORDINATES
  GRID_ALREADY_EXISTS
  GRID_OVERLAPS_EXISTING
  GAMERTAG_ALREADY_EXISTS
}
```
