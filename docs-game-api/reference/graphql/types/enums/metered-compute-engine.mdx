Which engine's meter produced a quantity of compute units. "expression" is the model expression engine (player invokes, automations and timers); "studio&#x005F;wasm" is developer-authored compute modules; "player&#x005F;wasm" is the player compute tier, which has its own tables and its own billed metric.


```graphql
enum MeteredComputeEngine {
  EXPRESSION
  STUDIO_WASM
  PLAYER_WASM
}
```
