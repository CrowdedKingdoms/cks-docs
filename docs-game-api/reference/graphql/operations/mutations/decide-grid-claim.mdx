Approve or deny a pending grid claim request (claim policy APPROVAL). Callable by the app's designated approver users or studio staff holding manage&#x005F;compute. Approval assigns grid&#x005F;ownership to the requester.


```graphql
decideGridClaim(
  appId: BigInt!
  requestId: String!
  approve: Boolean!
): GridClaimRequest!
```
