Install a listing onto a grid you own as your own mod, switched off (dev-tier preview; no payments). Requires being the grid's current owner and 'write&#x005F;server&#x005F;code' on both the app tier and the grid.


```graphql
execModInstall(
  appId: BigInt!
  gridId: BigInt!
  name: String!
  listingId: BigInt!
): ExecMod!
```
