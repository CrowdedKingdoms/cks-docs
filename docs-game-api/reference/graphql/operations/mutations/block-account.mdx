ADMIN/DESTRUCTIVE: blocks an account platform-wide. Every session and app token it holds is revoked, its realtime sessions and ck-exec sockets (developer sessions too) end in every datacenter, its mods stop, and every later sign-in and request, on CK and on Crowd Altar, is refused with ACCOUNT&#x005F;BLOCKED until `until` (or until unblockAccount when absent). Not yourself, not a super-admin. Requires a super-admin bearer game token.


```graphql
blockAccount(
  userId: BigInt!
  reason: String!
  until: DateTime
): AccountBlock!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AccountBlock</b></code>](/reference/graphql/types/objects/account-block.mdx) <Badge class="badge badge--secondary " text="object"/> 
A platform-wide block on an account, set by a super-admin. While it holds, every sign-in and every authenticated request is refused with ACCOUNT&#x005F;BLOCKED, on CK and on Crowd Altar, and every session, realtime connection and ck-exec socket the account had was ended when it was set. The last block stays readable after it is lifted or lapses.
