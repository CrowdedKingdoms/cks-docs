Update an existing access tier (name, ordering, pricing, permissions, etc.); only fields present in the input are changed. Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app that owns the tier (resolved from tierId); super admins bypass. SIDE EFFECTS: re-syncs the tier's permissions to the game API. Throws if the tier is not found or the caller lacks permission.


```graphql
updateAccessTier(
  tierId: BigInt!
  input: UpdateAccessTierInput!
): AppAccessTier!
```
