Enable or disable a compute module. Enabling requires a deployed version and resets the module's circuit breaker; disabling stops all scheduling. Requires the org 'manage&#x005F;compute' permission.


```graphql
computeSetModuleEnabled(
  appId: BigInt!
  name: String!
  enabled: Boolean!
): WasmModule!
```
