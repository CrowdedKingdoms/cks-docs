The mods kill ladder (dev-tier preview): switch off one mod, a player's mods, a grid's mods, a listing's installs or every mod in the app, or back on. Off stops what runs at once and refuses calls. Returns the switches that are off. Requires the org 'manage&#x005F;compute' permission.


```graphql
execModSetSwitch(
  appId: BigInt!
  scope: ExecModScope!
  off: Boolean!
  target: String
  reason: String
): [ExecModSwitch!]!
```
