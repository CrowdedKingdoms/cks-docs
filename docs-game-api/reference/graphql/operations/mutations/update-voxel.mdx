Records (upserts) a single voxel edit in the voxel&#x005F;updates log for one chunk and returns the resulting Voxel. WRITES world state; a background maintenance job later folds these edits into the chunk's packed grid. Requires a valid bearer token AND voxel-edit permission for the target region: the user must have active app access, the `update_voxel_data` tier permission, and (when grids cover the chunk) `update_voxel_data` on a covering grid.


```graphql
updateVoxel(
  input: UpdateVoxelInput!
): Voxel!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>Voxel</b></code>](/reference/graphql/types/objects/voxel.mdx) <Badge class="badge badge--secondary " text="object"/>
A recorded edit to a single voxel (one row of the voxel&#x005F;updates log): the app/chunk/local-position that changed, the new voxel type, an optional state blob, and who/when. Returned by listVoxels, getVoxelList and listVoxelUpdatesByDistance; created by updateVoxel. A background maintenance job later folds these edits into the chunk grid.
