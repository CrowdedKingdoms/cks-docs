The kill switch for an app's ck-exec code, or one node type of it (dev-tier preview). Switched off, nothing of it is placed, what runs is persisted and stopped, and calls are refused with `Denied`; switched on, instances start as they are called. Requires the org 'manage&#x005F;compute' permission.


```graphql
execSetEnabled(
  appId: BigInt!
  enabled: Boolean!
  nodeType: String
): ExecAppStatus!
```
