Create or update a WASM compute module (metadata only). Modules hold developer-authored Rust compiled to sandboxed WASM on game-api instances; upload source with computeDeployVersion. New modules start disabled. Upsert key is (app, name). Requires the org 'manage&#x005F;compute' permission.


```graphql
computeUpsertModule(
  input: UpsertComputeModuleInput!
): WasmModule!
```
