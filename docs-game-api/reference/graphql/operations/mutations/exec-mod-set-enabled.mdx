Switch a mod on your grid on or off (dev-tier preview). On, it runs as you once the app's code admission admits it. Requires being the grid's current owner and 'run&#x005F;server&#x005F;code' on both the app tier and the grid.


```graphql
execModSetEnabled(
  appId: BigInt!
  gridId: BigInt!
  name: String!
  enabled: Boolean!
): ExecMod!
```
