Begins vaulting a card for off-session auto-billing. Returns a Stripe SetupIntent client secret the browser confirms; no charge is made here. Requires the 'manage&#x005F;billing' org permission.


```graphql
setupSharedPaymentMethod(
  orgId: BigInt!
  idempotencyKey: String
): PaymentMethodSetup!
```

Organization id (BigInt) to vault a payment method for.


#### [<code style={{ fontWeight: 'normal' }}>setupSharedPaymentMethod.<b>idempotencyKey</b></code>](#idempotency-key)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#idempotency-key\} 
Optional idempotency key. Recommended for retries: replaying with the same key and identical arguments returns the first result instead of re-applying; the same key with different arguments returns IDEMPOTENCY&#x005F;CONFLICT. Keys expire after 24h.
