Create a marketplace listing (free mode) for code the caller authors — personally, or org-owned via ownerOrgId (DN-9; requires manage&#x005F;compute in that org). SIDE EFFECTS: the catalog row is written on cks-management-api with an ownership audit entry and replica-synced back. Publishing never uploads source; versions snapshot artifact hashes only.


```graphql
publishPlayerCode(
  input: PublishPlayerCodeInput!
): PlayerCodeListing!
```
