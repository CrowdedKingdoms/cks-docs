Publish a mod of yours, at its current version, for other grid owners in the app to install (dev-tier preview; no payments). Requires being the grid's current owner and 'write&#x005F;server&#x005F;code' on both the app tier and the grid.


```graphql
execModPublish(
  appId: BigInt!
  gridId: BigInt!
  name: String!
  title: String!
  description: String
): ExecModListing!
```
