Record that an open report was submitted to NCMEC's CyberTipline, under the CyberTipline report's id: its preserved copy is kept under COMPLIANCE retention for a year from now (nobody can delete it sooner), and the reported account's legal hold, if any, for as long. Escalating it again under the same id changes nothing; under another id is CONFLICT; a resolved report cannot be escalated (BAD&#x005F;REQUEST). Requires 'moderate&#x005F;safety' on the app (an org role, or the org's admins); super admins bypass. Send the identity session to the app's datacenter.


```graphql
escalateSafetyReport(
  appId: BigInt!
  reportId: BigInt!
  ncmecReportId: String!
): SafetyReport!
```
