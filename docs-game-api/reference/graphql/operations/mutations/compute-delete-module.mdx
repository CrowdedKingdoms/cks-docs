Delete a compute module and (via cascade) its versions, triggers, and lease. Run history is retained for auditing. Returns true when a module was deleted. Requires the org 'manage&#x005F;compute' permission.


```graphql
computeDeleteModule(
  appId: BigInt!
  name: String!
): Boolean!
```
