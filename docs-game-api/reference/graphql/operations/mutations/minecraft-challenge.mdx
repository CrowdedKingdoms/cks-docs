Start a Minecraft sign-in: a one-time server id for the app, good for two minutes. The client mod joins it through Mojang's session service as the account signed in to the game (the request a client makes to join any online-mode server), then calls signInWithMinecraft. Ask for it yourself: never join a server id something else hands you. Open only to Crowded Kingdoms' own apps (FORBIDDEN otherwise; FEATURE&#x005F;DISABLED on a tier without Minecraft sign-in). Public; rate-limited per address.


```graphql
minecraftChallenge(
  appId: BigInt!
): MinecraftChallenge!
```
