Hand the session host role to another joined participant. Session host or app admin ('manage&#x005F;apps'); expectedHostTerm refuses a stale host. Increments hostTerm and emits host&#x005F;changed. Requires a valid token.


```graphql
gameModelTransferSessionHost(
  input: TransferSessionHostInput!
): GmSession!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>gameModelTransferSessionHost.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>TransferSessionHostInput!</b></code>](/reference/graphql/types/inputs/transfer-session-host-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\} 
The app, the session id, the joined participant who becomes host, and optionally the host term you last read.
