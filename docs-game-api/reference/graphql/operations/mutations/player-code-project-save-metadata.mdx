Optimistically save selected private project metadata and increment its monotonic revision. Requires an app-scoped token and exact project ownership. A stale expectedRevision returns CONFLICT; grid affinity remains an authoring hint and never bypasses player-compute deployment checks.


```graphql
playerCodeProjectSaveMetadata(
  input: SavePlayerCodeProjectMetadataInput!
): PlayerCodeProject!
```

#### [<code style={{ fontWeight: 'normal' }}>playerCodeProjectSaveMetadata.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>SavePlayerCodeProjectMetadataInput!</b></code>](/reference/graphql/types/inputs/save-player-code-project-metadata-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\} 
Project id, expected revision, selected metadata changes, and optional retry key.

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerCodeProject</b></code>](/reference/graphql/types/objects/player-code-project.mdx) <Badge class="badge badge--secondary " text="object"/>
