Dev only. Delete a managed player: its sessions end and its row is anonymized, as an account deletion is. Signing the same external id in again creates a new player. False when there was no such player. An org token with players:manage, or an org admin with manage&#x005F;players.


```graphql
deleteManagedPlayer(
  orgId: BigInt!
  externalId: String!
): Boolean!
```
