Transfer a listing between personal and org ownership (DN-9). The caller must be the current owner (user-owned) or hold manage&#x005F;compute in the owning org; transfers to an org require manage&#x005F;compute in the receiving org. SIDE EFFECTS: append-only ownership audit row + replica sync to game-api. Ownership moves listing control and source-access rights; from P4b it also moves proceeds.

  input: TransferPlayerCodeListingInput!
