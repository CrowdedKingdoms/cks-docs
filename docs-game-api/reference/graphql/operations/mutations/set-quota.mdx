Creates or updates a quota enforcement rule (idempotent upsert keyed by org/app/tier + metric + period) and returns it. Scope is inferred from the input ids: an app-scoped rule requires the 'manage&#x005F;quotas' app permission, an org-scoped rule requires the 'manage&#x005F;quotas' org permission, and a global rule (no org/app/tier) requires super admin. Changes which limit `effectiveQuota` resolves for the metric; does not retroactively alter past usage.


```graphql
setQuota(
  input: SetQuotaInput!
): ServiceQuota!
```
