Buy a grid listing with real money (P4b). Debits the player wallet management-side (platform/org split), then assigns grid&#x005F;ownership + the listed player-code keys atomically; a failure to apply ownership refunds the charge. For blueprint listings, targetChunk picks where the fresh grid is stamped. This is the ownership path for marketplace&#x005F;only-policy apps.


```graphql
purchaseGrid(
  appId: BigInt!
  gridListingId: String!
  chunkX: Int
  chunkY: Int
  chunkZ: Int
): GridPurchaseResult!
```
