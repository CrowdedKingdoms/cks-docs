Deploy a mod build of yours to a grid you own (dev-tier preview): a new mod starts switched off; a running one restarts on the new version. Requires being the grid's current owner and 'write&#x005F;server&#x005F;code' on both the app tier and the grid.


```graphql
execModDeploy(
  appId: BigInt!
  gridId: BigInt!
  name: String!
  buildId: String!
): ExecMod!
```
