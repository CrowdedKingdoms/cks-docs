Mints a new org token (it starts with `cko_`) and returns the plaintext exactly once - save it, since subsequent queries only show metadata. An org token is the organization's SERVER credential for its org-managed players: with scope 'players:mint' its server signs the org's own players in (mintManagedPlayerToken), with 'players:manage' it manages them; `appIds` limits it to some of the org's apps. Never put one in a game client or a web page: a request with an Origin header is refused. Requires the 'manage&#x005F;tokens' permission on the target org (super admins bypass).


```graphql
createOrgToken(
  input: CreateOrgTokenInput!
): OrgTokenWithSecret!
```
