Remove a member from a channel. Requires the 'manage&#x005F;members' channel permission, except that any member may remove themselves. Notifies Buddy to stop routing to the removed member. Returns true if a membership was removed.


```graphql
removeChannelMember(
  groupId: BigInt!
  userId: BigInt!
): Boolean!
```
