OPERATOR ONLY. Retires an organization: sets organizations.status to 'retired', stamps deleted&#x005F;at, archives its apps, and writes a tombstone to org&#x005F;retirements. RETIREMENT IS A STATE, NOT A DELETION — no wallet&#x005F;transactions, org&#x005F;billing&#x005F;waivers, app&#x005F;shared&#x005F;usage&#x005F;charges or other ledger row is altered or removed, so an auditor can still reconstruct exactly what this organization spent, with the same joins as before, indefinitely. There is deliberately no purge and no retention window: destroying financial records is an operator and legal decision, not this mutation's. AFTER RETIREMENT the org's API tokens stop authenticating, its members lose every org permission (super admins excepted, so this is reversible), and it is excluded from the caller's organization list — but it is still readable by id and slug, because a retired org that answers like a missing one is worse than one that says what it is. Refuses unless expectedSlug matches the org named by orgId, and refuses an organization holding money unless acknowledgeFrozenBalance is passed. Reverse it with reinstateOrganization.

#### [<code style={{ fontWeight: 'normal' }}><b>OrgRetirementType</b></code>](/reference/graphql/types/objects/org-retirement-type.mdx) <Badge class="badge badge--secondary " text="object"/> 
A record of one organization retirement. Retirement is a STATE, not a deletion: every ledger row the organization ever wrote is still present and still references it, so what the org spent stays reconstructable with the same joins as before. This row says who retired it, why, and what it was holding at the time.
