Renew a RENT acquisition (or extend a TIME&#x005F;LIMITED window): a wallet charge on the same acquisition that pushes its expiry out. A drained install resumes on the next scheduler pass without re-consent. Paid modes only (P4b).


```graphql
renewPlayerCodeAcquisition(
  appId: BigInt!
  acquisitionId: String!
): PlayerCodeAcquisition!
```
