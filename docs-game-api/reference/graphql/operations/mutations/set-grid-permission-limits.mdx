Replace the whitelist of permission keys allowed on a grid (writes the `grid_permission_limits` input table), then recompute the grid's materialized effective ACL so any keys no longer on the whitelist are dropped for all users. Pass an empty array to remove all limits. Requires app-admin ('manage&#x005F;apps'). DESTRUCTIVE: narrowing the whitelist can strip effective permissions from existing users on the grid.


```graphql
setGridPermissionLimits(
  input: SetGridPermissionLimitsInput!
): GridPermissionLimits!
```

The app, grid, and the new whitelist of allowed permission keys (empty array = no limit).
