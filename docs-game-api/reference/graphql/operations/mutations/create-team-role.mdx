Create a custom (non-system) team role granting the given team permission keys. Requires the 'manage&#x005F;roles' team permission (app admins bypass). Permission keys must be valid team permission keys (group&#x005F;permission&#x005F;defs).


```graphql
createTeamRole(
  input: CreateGroupRoleInput!
): GroupRole!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>createTeamRole.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>CreateGroupRoleInput!</b></code>](/reference/graphql/types/inputs/create-group-role-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\} 
The team, the role name, the team permission keys to grant, and an optional rank.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GroupRole</b></code>](/reference/graphql/types/objects/group-role.mdx) <Badge class="badge badge--secondary " text="object"/> 
A role within a group (team/channel). Carries the group-management permission keys it grants (e.g. manage&#x005F;members), NOT world/runtime grid permissions.
