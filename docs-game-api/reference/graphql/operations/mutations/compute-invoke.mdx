Invoke a compute module's client-callable export (a trigger with triggerType=invoke). Synchronous RPC: the module runs and returns its result directly (unlike the spatial send surface's dual-success model). Authorization: the export's invoke policy (authority tree) — or holders of 'manage&#x005F;compute' only when no policy is set. Requires a valid app token.


```graphql
computeInvoke(
  appId: BigInt!
  moduleName: String!
  exportName: String!
  paramsJson: String
): ComputeInvokeResult!
```
