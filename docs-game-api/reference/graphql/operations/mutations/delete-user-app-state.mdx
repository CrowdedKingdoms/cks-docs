DESTRUCTIVE: deletes the authenticated user’s per-app state row for `appId` and returns the deleted row. Requires a valid game token; acts only on the caller’s own state. Throws NotFound when no row exists.


```graphql
deleteUserAppState(
  appId: BigInt!
): UserAppState!
```
