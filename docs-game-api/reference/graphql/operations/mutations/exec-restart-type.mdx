Moves one node type's running instances to the app's active version: each is persisted and stopped, and starts again on the active version at its next call. A deploy (execDeploy, execActivateVersion) changes which version NEW instances run but leaves running ones on theirs until they stop; this is how to move them without switching the type off. Requires the org 'manage&#x005F;compute' permission.


```graphql
execRestartType(
  appId: BigInt!
  nodeType: String!
): ExecRestartResult!
```
