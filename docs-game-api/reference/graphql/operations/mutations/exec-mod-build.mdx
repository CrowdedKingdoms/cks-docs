Build a mod from one ckx-sdk crate (dev-tier preview), as `execBuild` builds a developer's crates. Returns at once with the build queued; poll `execModBuildStatus`, then pass its id to `execModDeploy`. One build at a time per player. Requires the 'write&#x005F;server&#x005F;code' permission in the app.


```graphql
execModBuild(
  appId: BigInt!
  crate: ExecBuildCrateInput!
): ExecBuild!
```
