Saves answers to the organization's project profile. An omitted field keeps its answer; null clears it. When every answer but anythingElse is in, the profile is complete and waits for Crowded Kingdoms' review; approved, it earns the PROFILE free tier level from the start of the next month. Next month's level is checked again at once. Requires the 'manage&#x005F;billing' org permission.


```graphql
setOrgProjectProfile(
  input: SetOrgProjectProfileInput!
): OrgProjectProfile!
```
