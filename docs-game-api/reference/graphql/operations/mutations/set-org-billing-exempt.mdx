OPERATOR ONLY. Sets or clears an organization billing exemption. When true, org-wallet debits and money-driven runtime denials are skipped; usage is still metered and every waived amount is written to org&#x005F;billing&#x005F;waivers. Does not waive player-wallet charges, failure breakers, or the per-minute compute budget. reason is required when setting true. SIDE EFFECT: re-evaluates the runtime gate for every shared app in the org, so clearing the exemption re-denies immediately instead of waiting for the next hourly tick.


```graphql
setOrgBillingExempt(
  orgId: BigInt!
  exempt: Boolean!
  reason: String!
): BillingExemptOrgType!
```
