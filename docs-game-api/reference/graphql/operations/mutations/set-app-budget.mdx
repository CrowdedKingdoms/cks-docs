Creates or updates an app's monthly spend cap (idempotent upsert keyed by org + app) and returns the resulting budget. This only records the cap used to monitor/limit overspend; it does not move money, charge a card, or alter the wallet balance. Requires the 'manage&#x005F;billing' app permission.


```graphql
setAppBudget(
  orgId: BigInt!
  appId: BigInt!
  monthlyLimitCents: BigInt!
  idempotencyKey: String
): AppBudget!
```
