Synchronously invoke a server player-module export as the current grid owner. Requires the module to be enabled, compiled, admitted, and covered by run&#x005F;server&#x005F;code at app and grid scope. The runtime payload carries callerUserId/gridId; author identity never participates.


```graphql
playerComputeInvoke(
  appId: BigInt!
  gridId: BigInt!
  moduleName: String!
  exportName: String!
  paramsJson: String
): PlayerComputeInvokeResult!
```
