Assign first-class title for an unowned grid to one user. P1 studio/bootstrap path; marketplace acquisition supersedes it later. Requires app-admin ('manage&#x005F;apps'). Assigns title only: permissions must be granted explicitly.


```graphql
assignGridOwnership(
  input: AssignGridOwnershipInput!
): GridOwnership!
```
