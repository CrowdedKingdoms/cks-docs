Delete a directed relationship edge between two containers. Allowed for an app admin or the owner of the source (from) container. Requires a valid token. DESTRUCTIVE. Returns true if an edge was deleted.


```graphql
gameModelDeleteEdge(
  appId: BigInt!
  edgeId: String!
): Boolean!
```
