Delete a non-system channel role. Requires the 'manage&#x005F;roles' channel permission (app admins bypass). The system 'leader' role cannot be deleted. DESTRUCTIVE: removes the role from members. Returns true if a role was deleted.


```graphql
deleteChannelRole(
  groupRoleId: BigInt!
): Boolean!
```
