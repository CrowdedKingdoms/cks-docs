Delete a channel. Requires the 'manage&#x005F;group' channel permission (app admins bypass). DESTRUCTIVE: cascades to members and roles and notifies Buddy servers to tear down message routing for the channel. Returns true on success.


```graphql
deleteChannel(
  groupId: BigInt!
): Boolean!
```
