Top up a COST&#x005F;LIMITED acquisition's compute-unit budget: a wallet charge that adds the listing's unit budget to the license. Exhausted installs resume once the budget clears their consumed units. Paid modes only (P4b).


```graphql
topUpPlayerCodeAcquisition(
  appId: BigInt!
  acquisitionId: String!
): PlayerCodeAcquisition!
```
