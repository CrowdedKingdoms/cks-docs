Create an event trigger that fires an automation in reaction to model activity (a function invocation, a direct property write, or a container creation). Matched in the API server post-commit. Requires app-admin ('manage&#x005F;apps').


```graphql
gameModelUpsertAutomationTrigger(
  input: UpsertAutomationTriggerInput!
): GmAutomationTrigger!
```

#### [<code style={{ fontWeight: 'normal' }}>gameModelUpsertAutomationTrigger.<b>input</b></code>](#input)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>UpsertAutomationTriggerInput!</b></code>](/reference/graphql/types/inputs/upsert-automation-trigger-input.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="input"/> \{#input\}
The app, the target automation (by name), the model event, and optional filters.
