Amounts the platform could not bill this org for, with the reason (an exempt org, a provider with no generation record, a process that died with metered usage in memory). Requires 'view&#x005F;billing' on the org.


```graphql
billingWriteOffs(
  orgId: BigInt!
  limit: Int
): [BillingWriteOff!]!
```
