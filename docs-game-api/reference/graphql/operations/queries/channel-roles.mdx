List the roles of a channel, including the system 'leader' role and any default 'member' role (which typically grants send&#x005F;messages).


```graphql
channelRoles(
  groupId: BigInt!
): [GroupRole!]!
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>channelRoles.<b>groupId</b></code>](#group-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#group-id\}
The channel whose roles to list.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>GroupRole</b></code>](/reference/graphql/types/objects/group-role.mdx) <Badge class="badge badge--secondary " text="object"/>
A role within a group (team/channel). Carries the group-management permission keys it grants (e.g. manage&#x005F;members), NOT world/runtime grid permissions.
