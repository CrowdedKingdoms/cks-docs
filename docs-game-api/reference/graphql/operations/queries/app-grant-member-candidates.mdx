Lists org members eligible for a manual app access grant (active members of the app's owning org). Requires the 'manage&#x005F;access&#x005F;tiers' permission on the app; super admins bypass. Use the returned user ids with grantAppAccess.


```graphql
appGrantMemberCandidates(
  appId: BigInt!
): [AppGrantMemberCandidate!]!
```
