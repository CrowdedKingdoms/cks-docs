:::warning[DEPRECATED]

Reads the hourly cents-era charge rows, which the lossless ledger does not write. Read playerWalletTransactions: each "usage&#x005F;debit" entry is one charge, per app, markup included.

:::

The caller's hourly player-usage charges from the cents-era billing, newest first, optionally filtered by app. Nothing has been added since the lossless ledger took over; current usage charges are the "usage&#x005F;debit" entries in playerWalletTransactions.


```graphql
playerUsageCharges(
  appId: BigInt
  limit: Int
): [PlayerUsageCharge!]! @deprecated
```

#### [<code style={{ fontWeight: 'normal' }}>playerUsageCharges.<b>limit</b></code>](#limit)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>Int</b></code>](/reference/graphql/types/scalars/int.mdx) <Badge class="badge badge--secondary " text="scalar"/> {/* #limit */}

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>PlayerUsageCharge</b></code>](/reference/graphql/types/objects/player-usage-charge.mdx) <Badge class="badge badge--secondary " text="object"/> 
One player usage charge from the hourly cents-era billing: a (player, app, closed clock hour) row. The lossless ledger, on by default, replaced that billing and writes no rows here, so the list ends where the ledger took over; usage since is in playerWalletTransactions as "usage&#x005F;debit" entries. amountCents = platformCents + markupCents: what the platform charged and what the studio added.
