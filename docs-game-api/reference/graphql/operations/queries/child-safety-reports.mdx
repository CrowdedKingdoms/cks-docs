OPERATOR: CK's child-safety queue (decision 41), the CHILD&#x005F;SAFETY reports of every app, open ones first, then the newest; only those with the given status if one is given. At most `first` (default 50, at most 200). Each report is also announced to CK's abuse inbox when it is filed. The app's own moderators still read and decide it (safetyReports, resolveSafetyReport, escalateSafetyReport); operators read its evidence with exportPlayerData. Send the identity session; any datacenter answers.


```graphql
childSafetyReports(
  status: SafetyReportStatus
  first: Int = 50
): [SafetyReport!]!
```
