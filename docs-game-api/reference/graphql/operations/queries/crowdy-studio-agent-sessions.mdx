List the authenticated owner’s Agentic Crowdy Studio sessions in one app using an opaque cursor, newest first. Requires an app-scoped token for appId and use&#x005F;studio&#x005F;agent. The bounded page defaults to 20 and allows 1–50.


```graphql
crowdyStudioAgentSessions(
  appId: BigInt!
  after: String
  first: Int
): AgentSessionConnection!
```
