List containers in an app, optionally filtered by container type and/or session. Requires a valid token.


```graphql
gameModelContainers(
  appId: BigInt!
  typeName: String
  sessionId: String
): [GmContainer!]!
```

The app (tenant) whose containers to list.


#### [<code style={{ fontWeight: 'normal' }}>gameModelContainers.<b>typeName</b></code>](#type-name)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#type-name\} 
Optional: only containers of this type. Omit for all types.


#### [<code style={{ fontWeight: 'normal' }}>gameModelContainers.<b>sessionId</b></code>](#session-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>String</b></code>](/reference/graphql/types/scalars/string.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#session-id\}
