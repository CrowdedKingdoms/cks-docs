An app's mods, by grid or by owner, or all of them (at most 1000) (dev-tier preview). Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
execAppMods(
  appId: BigInt!
  gridId: BigInt
  ownerId: BigInt
): [ExecMod!]!
```

The app the grid is in.


#### [<code style={{ fontWeight: 'normal' }}>execAppMods.<b>gridId</b></code>](#grid-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#grid-id\} 
Only this grid’s mods.


#### [<code style={{ fontWeight: 'normal' }}>execAppMods.<b>ownerId</b></code>](#owner-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary " text="scalar"/> \{#owner-id\} 
Only the mods this player owns.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>ExecMod</b></code>](/reference/graphql/types/objects/exec-mod.mdx) <Badge class="badge badge--secondary " text="object"/> 
A mod: a player’s code on a grid they own, run by ck-exec as the hub `mod:<name>` keyed by the grid id, in its owner’s own sandbox (dev-tier preview).
