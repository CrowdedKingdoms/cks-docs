Reads one avatar’s per-app state (keyed by appId+avatarId). PUBLIC READ: any authenticated user may read it. Requires a valid game token. Returns null when no row exists. `state` is base64-encoded binary.


```graphql
avatarAppState(
  appId: BigInt!
  avatarId: BigInt!
): AppAvatarState
```
