List the compute modules defined for an app. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
computeModules(
  appId: BigInt!
): [WasmModule!]!
```

### Type

#### [<code style={{ fontWeight: 'normal' }}><b>WasmModule</b></code>](/reference/graphql/types/objects/wasm-module.mdx) <Badge class="badge badge--secondary " text="object"/>
A WASM compute module: developer-authored Rust compiled to sandboxed WASM on game-api instances. Holds metadata, the deployed version pointer, and circuit-breaker state; source lives in versions.
