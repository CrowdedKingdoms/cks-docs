The app's safety reports, newest first, with open CHILD&#x005F;SAFETY reports ahead of the rest; only those with the given status if one is given. At most `first` (default 50, at most 200). Requires 'moderate&#x005F;safety' on the app (an org role, or the org's admins); super admins bypass. Send the identity session to the app's datacenter.


```graphql
safetyReports(
  appId: BigInt!
  status: SafetyReportStatus
  first: Int = 50
): [SafetyReport!]!
```
