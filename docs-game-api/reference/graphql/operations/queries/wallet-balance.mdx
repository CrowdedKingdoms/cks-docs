Returns the organization's wallet, creating an empty zero-balance wallet on first access if one does not yet exist (so it never returns null). Use it to read the current balance and currency before charging usage or topping up. Requires the 'view&#x005F;billing' org permission.


```graphql
walletBalance(
  orgId: BigInt!
): OrgWallet!
```
