Diagnostic log lines for an app's compute modules, newest first: failed-run errors from the runtime plus guest ck.log output. Complete across the fleet — each line carries the instance that produced it. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
computeModuleLogs(
  appId: BigInt!
  moduleName: String
  limit: Int
): [WasmModuleLogEntry!]!
```
