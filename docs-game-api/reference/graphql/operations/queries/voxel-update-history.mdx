Returns entries from the immutable voxel edit history (voxel&#x005F;updates&#x005F;history) for an app, newest first, optionally filtered by user id and a changed-at time window. Returns up to `limit` entries (DEFAULT 500, max 50000) starting at `offset`. Requires a valid bearer token; app-scoped tokens are limited to their own app. Read-only.


```graphql
voxelUpdateHistory(
  appId: BigInt!
  userId: BigInt
  from: DateTime
  to: DateTime
  limit: Int
  offset: Int
): [VoxelUpdateHistoryEvent!]!
```
