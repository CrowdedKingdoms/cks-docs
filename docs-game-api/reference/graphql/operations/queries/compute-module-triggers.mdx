List trigger bindings for an app, optionally filtered to one module. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
computeModuleTriggers(
  appId: BigInt!
  moduleName: String
): [WasmModuleTrigger!]!
```

#### [<code style={{ fontWeight: 'normal' }}><b>WasmModuleTrigger</b></code>](/reference/graphql/types/objects/wasm-module-trigger.mdx) <Badge class="badge badge--secondary " text="object"/>
