The authenticated caller's own access record for a given app, or null if they have none. Requires authentication. Use this to check whether the current user is entitled to the app and on which tier; inspect status to distinguish active vs revoked.


```graphql
myAppAccess(
  appId: BigInt!
): AppUserAccess
```


### Arguments

#### [<code style={{ fontWeight: 'normal' }}>myAppAccess.<b>appId</b></code>](#app-id)<Bullet />[<code style={{ fontWeight: 'normal' }}><b>BigInt!</b></code>](/reference/graphql/types/scalars/big-int.mdx) <Badge class="badge badge--secondary badge--non_null" text="non-null"/> <Badge class="badge badge--secondary " text="scalar"/> \{#app-id\} 
Numeric id of the app to check the caller's access for.




### Type

#### [<code style={{ fontWeight: 'normal' }}><b>AppUserAccess</b></code>](/reference/graphql/types/objects/app-user-access.mdx) <Badge class="badge badge--secondary " text="object"/> 
A user's entitlement to a specific app: whether (and via which tier) they may access it. At most one row per (app, user).
