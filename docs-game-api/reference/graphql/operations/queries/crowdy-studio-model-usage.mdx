The caller's own model usage in this app: today's request count and rate-carded charge against the policy ceiling, the payer (PLAYER wallet by default, ORG when the app elected it, PLATFORM while platform-funded), and the most recent requests. Counts and charges only; no prompts or provider bodies exist to return. Requires 'use&#x005F;studio&#x005F;agent'.


```graphql
crowdyStudioModelUsage(
  appId: BigInt!
  limit: Int = 20
): CrowdyStudioModelUsage!
```
