List a module's source versions, newest first, including compile status/logs. Requires the org 'view&#x005F;compute&#x005F;diagnostics' permission.


```graphql
computeModuleVersions(
  appId: BigInt!
  moduleName: String!
  limit: Int
): [WasmModuleVersion!]!
```
