List an app's code acquisitions (entitlement rows), newest first. Requires 'view&#x005F;compute&#x005F;diagnostics'. All rows are mode FREE in P4a; uninstalls never delete acquisitions (audit).


```graphql
appPlayerCodeAcquisitions(
  appId: BigInt!
): [PlayerCodeAcquisition!]!
```
